Traffic Meta

Tutorial completo de instalação e uso da skill que conecta Meta Ads ao Claude Code e Claude Desktop em poucos minutos.

por Juliano Torriani · Maio/2026

01O que é o Traffic Meta?

É uma skill (extensão) do Claude Code que permite operar o Meta Ads (Facebook + Instagram) direto do terminal — sem abrir o Ads Manager.

Por que isso importa? Você consegue rodar análises, ver performance de campanhas, diagnosticar pixel/CAPI, identificar oportunidades — tudo conversando com o Claude. Em segundos, não em horas.

O que você consegue fazer depois de instalar

  • 📊 Daily pulse — resumo dos últimos 7 dias da sua conta
  • 🎯 Análise de leads — Lead Form nativo + via pixel
  • 🔬 Health-check — diagnóstico do pixel/CAPI
  • 💰 Insights por campanha/adset/criativo
  • 📈 Benchmark — performance vs indústria (via MCP)
  • 🚨 Anomalias — Meta avisa o que está fora do padrão

Existem dois caminhos para usar

CaminhoOndePara quem
Claude Code (CLI)TerminalQuem quer automação, scripts, análise técnica
Claude Desktop (MCP)App desktopQuem quer conversar via interface, sem terminal

Este tutorial mostra os dois — você decide qual usar (ou os dois).

03Instalar a Meta Ads CLI

A Meta lançou uma CLI oficial em 29/abril/2026 chamada meta-ads, distribuída via PyPI. É grátis.

1

Instale o uv (gerenciador Python moderno)

Abra o Terminal (Cmd+Space → "Terminal") e cole:

brew install uv

Não tem Homebrew? Instale antes em brew.sh.

2

Instale Python 3.12+

uv python install 3.12
3

Instale a Meta Ads CLI

uv tool install meta-ads
4

Verifique se funcionou

meta ads --help

Deve aparecer ajuda da CLI com subcomandos: ad, adaccount, campaign, insights...

04Gerar o token Meta (System User Token)

Você precisa de um token para autorizar o acesso. Use System User Token — ele não expira, diferente do token do Graph API Explorer (que expira em 60 dias).

⏱️ Tempo: ~5 minutos · 💰 Custo: grátis

1

Acesse o Business Manager

Abra business.facebook.com/settings/system-users

2

Crie um System User

Clique em + Add (canto superior direito) e preencha:

  • Nome: meta-cli-{seu-nome} (ex: meta-cli-juliano)
  • Role: Admin

Clique em Create System User.

3

Adicione Assets ao System User

Clique no usuário criado → Add Assets → marque:

  • ✅ Ad Accounts — todas as contas que você quer gerenciar (defina permissão "Manage campaigns")
  • ✅ Pages — Facebook Pages das suas marcas
  • ✅ Pixels/Datasets — pixels de tracking

Clique em Save Changes.

4

Gere o token

De volta na tela do System User, clique em Generate New Token:

  • App: selecione qualquer Meta Developer App. Não tem? Crie um em developers.facebook.com/apps tipo "Business" (qualquer nome)
  • Token Expiration: Never
  • Permissions: ✅ ads_management · ✅ ads_read · ✅ business_management

Clique em Generate Token.

5

Copie o token

⚠️ O token só aparece UMA vez. Se fechar a janela sem copiar, vai ter que gerar outro. Copie agora.

Token tem ~200 caracteres e começa com EAAi...

6

Persista no shell (não precisa colar toda vez)

No terminal:

echo '' >> ~/.zshrc
echo '# Meta Ads CLI' >> ~/.zshrc
echo 'export ACCESS_TOKEN="SEU_TOKEN_AQUI"' >> ~/.zshrc
echo 'export AD_ACCOUNT_ID="act_XXXXXXXXX"' >> ~/.zshrc
source ~/.zshrc

Substitua SEU_TOKEN_AQUI e act_XXXXXXXXX pelos seus valores.

O AD_ACCOUNT_ID você pega em business.facebook.com/settings/ad-accounts (formato act_123456789).

7

Teste

meta ads adaccount list

Deve aparecer uma tabela com suas contas. Se aparecer, ✅ está tudo certo.

05Configurar Claude Desktop + MCP

O Claude Desktop é o app gráfico (não é o Claude Code do terminal). É onde você usa o MCP oficial da Meta — tem ferramentas extra como opportunities, industry benchmark e anomaly signal.

1

Baixe o Claude Desktop

Acesse claude.ai/download e instale o app pra Mac/Windows.

2

Faça login

Abra o Claude Desktop e faça login com sua conta Anthropic (a mesma do claude.ai).

3

Conecte o MCP da Meta

No Claude Desktop:

  1. Vá em Settings → Connectors (ou Features → MCP dependendo da versão)
  2. Clique em Add MCP Server
  3. Cole a URL: https://mcp.facebook.com/ads
  4. Confirme
4

Autorize no Meta Business

Vai abrir o navegador. Faça login no Meta Business e:

  • Selecione quais Ad Accounts autorizar
  • Selecione Pages, Pixels, Catálogos
  • Escolha Read + Write (para criar campanhas) ou Read-only (só análise)

Confirme. O token é gerenciado pela Meta automaticamente.

5

Teste

De volta no Claude Desktop, peça:

"Mostra minhas contas Meta Ads"

Ele vai listar suas contas — está conectado.

✅ Vantagem do Claude Desktop: tem acesso às 29 ferramentas oficiais Meta, incluindo ads_get_opportunity_score, ads_insights_industry_benchmark e ads_insights_anomaly_signal — que NÃO estão na CLI.

09Troubleshooting

🔴 command not found: meta

Causa: CLI não foi instalada ou PATH não atualizado.

Fix:

uv tool install meta-ads
uv tool update-shell
source ~/.zshrc

Se persistir, abra novo terminal.

🔴 Invalid OAuth access token

Causa: Token expirado, vazio ou revogado.

Fix: Verifique:

echo $ACCESS_TOKEN | head -c 20

Deve aparecer EAAi.... Se vazio, persista no ~/.zshrc. Se aparecer mas inválido, gere novo System User Token (volte ao Passo 4).

🔴 adaccount list retorna array vazio

Causa: Token válido, mas System User não tem assets.

Fix: Volte em business.facebook.com/settings/system-users → seu System User → Add Assets → adicione Ad Accounts e defina permissão Manage campaigns.

🔴 Skill não aparece no Claude Code

Causa: a instalação não copiou a skill para ~/.claude/skills/coreai-traffic-meta.

Fix: peça pro Claude/Codex reler o README do pacote agentesIA e rodar o inventário do catálogo de skills de novo, instalando só o que estiver faltando. Nunca crie link manual nem apague a pasta ~/.claude/skills inteira: ela guarda as outras skills já instaladas.

Reinicie o Claude Code depois.

🔴 MCP não conecta no Claude Desktop

Causa: Internet, sessão expirada, ou conta sem assets.

Fix: Settings → Connectors → desconectar e reconectar https://mcp.facebook.com/ads. Reinicie Claude Desktop. Se persistir, autorize um System User dedicado em business.facebook.com/settings/people.

🔴 Token expirou (raro com System User)

Causa: Token foi revogado (manual ou política Meta).

Fix: Gere novo token em business.facebook.com/settings/system-users → System User → Generate New Token. Atualize ACCESS_TOKEN no ~/.zshrc.

🟡 Performance da CLI lenta

Causa: Rate limit Meta API (~200 calls/hora padrão).

Fix: Aguarde 5-15min. Para escalar, peça Marketing API Standard Access em developers.facebook.com.
