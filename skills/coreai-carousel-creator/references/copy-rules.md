# Regras de Copy para Carrosseis

## Limites de Palavras

| Elemento | Limite | Notas |
|----------|--------|-------|
| Slide 1 (Hook) | Max 15 palavras | Sem pergunta (exceto retorica via H6) |
| Slides 2-10 | Max 30 palavras | Concisao brutal |
| Prompt 5 (Ideias no Direct) | Max 10 palavras | Formato especial de engajamento |
| Gancho | Max 10 palavras | Primeira frase visivel |
| Subheadline | Max 7 palavras | Complemento do gancho |
| Caption | 170-250 palavras | Hook + contexto + CTA |

## Progressao Emocional (Obrigatoria)

Cada carrossel deve seguir a progressao em 3 fases:

```
Reptiliano (Slides 1-3)    → Medo, perigo, instinto de sobrevivencia
    ↓
Limbico (Slides 4-6)       → Conexao, desejo, pertencimento
    ↓
Neocortex (Slides 7-10)    → Decisao racional, acao, comando
```

## 7 Tipos de Post

| Tipo | Descricao | Abertura Ideal |
|------|-----------|---------------|
| Imperial | Doutrinacao + envolvimento + colapso | Provocacao |
| Polemico | Controversia como ponto de partida | Provocacao/Curiosidade |
| Crenca | Trocar sistema de crencas | Curiosidade |
| Problema | Agitar dor + apresentar solucao | Problema/Solucao |
| Curiosidade | Despertar fascinio por insight | Abertura Curiosa |
| Historia | Narrativa pessoal ou de cliente | Storytelling |
| Oferta | Venda direta com provas | Beneficio Direto/Autoridade |

## 9 Frameworks de Copy

1. **Abertura Curiosa** — Gancho que gera "como assim?"
2. **Autoridade** — Credenciais + resultados como prova
3. **Beneficio Direto** — Resultado tangivel na primeira frase
4. **Testemunho Real** — Historia de cliente com dados especificos
5. **Problema e Solucao** — Dor agitada → mecanismo de resolucao
6. **Pergunta Impactante** — Retorica disruptiva (unica excecao H6)
7. **Segredo Revelado** — Informacao "privilegiada" do insider
8. **Passo a Passo** — Metodo claro em etapas
9. **Comparacao** — Antes/depois ou certo/errado

## Matriz Intencao → Tipo + Framework

| Intencao | Tipos Recomendados | Frameworks Recomendados |
|----------|-------------------|------------------------|
| Atracao | Polemico, Curiosidade | Abertura Curiosa, Segredo Revelado |
| Consciencia | Imperial, Crenca | Problema/Solucao, Pergunta Impactante |
| Aquecimento | Historia, Problema | Testemunho Real, Autoridade |
| Venda | Oferta | Beneficio Direto, Passo a Passo |

## Adaptacao por Tamanho

| Slides | Estrutura |
|--------|-----------|
| 1 | Hook unico + CTA embutido (max 20 palavras) |
| 3 | Hook → Argumento central → CTA |
| 5 | Hook → Build-up → Climax → Resolucao → CTA |
| 7 | Hook → 2 Build-up → Climax → Nova crenca → Resolucao → CTA |
| 10 | Estrutura completa do tipo escolhido |

## 8 Heuristicas de Decisao

- **H1 (Imperial):** Abertura Provocacao. Arco completo Rept→Limb→Neo. CTA de comando moral.
- **H2 (Crenca):** Abertura Curiosidade. Slides 2-3 preparam. Slide 4 = virada.
- **H3 (Oferta):** Provas reais slides 3-8. Escassez REAL slide 9. CTA Imperial.
- **H4 (Curto 1-3):** Comprimir ao maximo. Impacto instantaneo, sem arco narrativo.
- **H5 (Medio 5-7):** Selecionar slides mais emocionais. Manter Hook + Conflito + Crenca Nova + CTA.
- **H6 (Pergunta):** Unica excecao para pergunta no S1. Deve ser retorica e disruptiva.
- **H7 (Testemunho):** S1 com resultado especifico (nome + numero + tempo). Sem dados = trocar framework.
- **H8 (Solucao Cedo):** Se solucao antes do slide 6 em carrossel de 10 → REESCREVER.

## Anti-Patterns (Proibido)

- Comecar S1 com pergunta (exceto H6)
- Ultrapassar word limits
- Revelar solucao antes do slide 6 (em 10 slides)
- CTA generico ("clique aqui", "link na bio", "me chama")
- Conteudo educativo puro sem tensao
- Ignorar progressao emocional
- Copiar hooks literalmente do banco
- Entregar sem 3 headlines + 3 CTAs
- Tom educativo ("vou te ensinar", "a dica e")
- Palavras proibidas: segredo, dica, truque, hack, simples, facil
- Foco no "eu" em vez do "voce"

## Checklist Pre-Entrega

- [ ] Slide 1: max 15 palavras, sem pergunta, contraintuitivo
- [ ] Slides 2-10: max 30 palavras cada
- [ ] 3 variacoes de headline geradas
- [ ] 3 opcoes de CTA geradas
- [ ] Progressao emocional respeitada
- [ ] Solucao nao revelada cedo demais
- [ ] Nenhum cliche proibido
- [ ] Tom persuasivo (nao educativo)
- [ ] Caption sugerida incluida
- [ ] Sugestoes de repurpose incluidas
