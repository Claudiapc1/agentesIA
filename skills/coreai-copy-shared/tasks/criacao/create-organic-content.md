## Objetivo

Criar conteúdo orgânico de alto engajamento no estilo Dan Koe - conteúdo que combina filosofia pessoal, expertise e persuasão sutil para construir audiência e autoridade enquanto naturalmente direciona para ofertas.

---

## Veto Conditions
- Nao criar conteudo organico sem persona/voz do autor definida
- Nao executar sem tema conectado ao ecosistema de oferta do expert
- Nao produzir sem definir plataforma e formato especifico (thread, carrossel, post)

## Steps de Execução

### Step 1: Definir o Ângulo Viral
```action
Elementos de conteúdo viral (Dan Koe style):
- Contrarian (contra o consenso)
- Relatable (identificação pessoal)
- Útil (aplicável imediatamente)
- Intrigante (faz pensar)
- Emocional (ressoa profundamente)
```

### Step 2: Estruturar o Hook
```action
O hook (primeira linha) deve:
- Parar o scroll
- Criar gap de curiosidade
- Prometer valor
- Qualificar o leitor

Fórmulas:
- "A maioria das pessoas [erro]. Aqui está o que [poucos] fazem diferente:"
- "Eu [resultado] fazendo o oposto do que [ensinam]."
- "[Crença comum] é uma mentira. Aqui está a verdade:"
- "Se você [situação], preste atenção:"
```

### Step 3: Desenvolver o Corpo
```action
Para Thread/Carrossel:
1. Hook (slide/tweet 1)
2. Contexto/Problema (2-3)
3. Insight/Solução (4-6)
4. Framework/Steps (7-9)
5. CTA/Conclusão (final)

Para Post Único:
- Hook → Desenvolvimento → Punchline/CTA
```

### Step 4: Criar Variações por Formato
```action
THREAD TWITTER/X:
- 7-12 tweets
- Cada tweet funciona sozinho
- Primeiro tweet = hook poderoso
- Último tweet = CTA + retweet request

CARROSSEL INSTAGRAM:
- 7-10 slides
- Texto grande e legível
- Um conceito por slide
- Design consistente
- CTA no último slide

POST LINKEDIN:
- 1200-1500 caracteres
- Parágrafos curtos
- Espaçamento visual
- História + insight + CTA

REELS/SHORTS SCRIPT:
- Hook em 2 segundos
- Duração 30-60 segundos
- Linguagem conversacional
- CTA no final
```

### Step 5: Adicionar Elementos de Engajamento
```action
- Perguntas retóricas
- "Concorda?" no final
- Pedido de opinião
- Convite para salvar/compartilhar
- Menção de DM aberta
```

### Step 6: Otimizar para Algoritmo
```action
- Evitar links no corpo (prejudica alcance)
- Usar keywords do nicho
- Timing de postagem
- Formato que retém atenção
- Incentivar comentários
```

## Fórmulas de Conteúdo (Dan Koe Style)

### 1. O Framework
```
[Conceito] é sobre [fundamento].

Aqui está o framework de [X] passos:

1. [Passo]
2. [Passo]
3. [Passo]

[Insight final]
```

### 2. O Contrarian
```
[Crença comum] é uma mentira.

Aqui está a verdade:

[Argumento 1]
[Argumento 2]
[Argumento 3]

[O que fazer em vez disso]
```

### 3. A História Pessoal
```
[X] anos atrás, eu [situação ruim].

Hoje, eu [situação boa].

Aqui está o que mudou:

[Insight 1]
[Insight 2]
[Insight 3]
```

### 4. A Observação
```
Eu notei algo sobre [grupo/situação].

[Observação detalhada]

Por que isso importa:

[Explicação]

O que fazer:

[Ação]
```

### 5. A Lista de Verdades
```
[X] verdades incômodas sobre [tópico]:

1. [Verdade] - [Explicação]
2. [Verdade] - [Explicação]
3. [Verdade] - [Explicação]

A maioria ignora. Poucos aplicam.
```

## Princípios Dan Koe

1. **Conteúdo é educação em público** - Ensine enquanto aprende
2. **Sua perspectiva é o diferencial** - Não seja genérico
3. **Value-first, sempre** - O valor vem antes da venda
4. **Construa em público** - Mostre a jornada, não só resultados
5. **Menos é mais** - Uma ideia clara > múltiplas confusas
6. **Consistência > Viralidade** - Poste todo dia, não espere hits
7. **Autenticidade escala** - Seja você, amplificado
