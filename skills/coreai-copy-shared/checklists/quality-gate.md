# Quality Gate de Copy

Este checklist é o gate obrigatório de qualidade para todas as peças de copy produzidas pelo squad. Nenhuma copy deve ser publicada sem passar por esta validação.

**Regra de Ouro:** Uma copy só é aprovada se atingir pelo menos 80% dos critérios aplicáveis.

---

## Gate 1: Clareza da Mensagem

### 1.1 Compreensão Imediata

**Critério:** A mensagem principal deve ser compreendida em 5 segundos ou menos.

- [ ] A proposta de valor está clara na primeira dobra/scroll
- [ ] Não há jargões inexplicados ou termos técnicos confusos
- [ ] Um leigo entenderia do que se trata
- [ ] A linguagem é apropriada para o público-alvo
- [ ] Siglas são explicadas na primeira ocorrência
- [ ] Metáforas são claras e universais

**Teste dos 5 Segundos:**
> Mostre a copy para alguém por 5 segundos. Pergunte: "Do que se trata?"
> - [ ] Resposta correta e completa
> - [ ] Resposta parcialmente correta
> - [ ] Resposta incorreta ou confusa

### 1.2 Hierarquia de Informação

**Critério:** Informações mais importantes vêm primeiro.

- [ ] Headline comunica benefício principal
- [ ] Subheadline expande/complementa headline
- [ ] Informações estão em ordem de importância
- [ ] Detalhes técnicos estão após benefícios
- [ ] Preço/oferta está no momento certo
- [ ] CTA está posicionado estrategicamente

### 1.3 Foco e Objetivo Único

**Critério:** Uma peça, um objetivo.

- [ ] Há apenas UM objetivo principal claramente definido
- [ ] Todas as seções convergem para esse objetivo
- [ ] Não há distrações ou tangentes
- [ ] Links/CTAs secundários são minimizados
- [ ] A jornada do leitor é linear e clara

## Gate 2: Estrutura Lógica

### 2.1 Fluxo Narrativo

**Critério:** A copy deve ter progressão lógica do início ao fim.

- [ ] Introdução captura atenção e estabelece contexto
- [ ] Desenvolvimento constrói argumento progressivamente
- [ ] Cada seção conecta naturalmente à próxima
- [ ] Transições são suaves e lógicas
- [ ] Conclusão é forte e direciona para ação
- [ ] Não há saltos de lógica ou non-sequiturs

### 2.2 Formatação Visual

**Critério:** A formatação facilita leitura e compreensão.

- [ ] Parágrafos curtos (máximo 4 linhas)
- [ ] Espaçamento adequado entre seções
- [ ] Bullet points para listas
- [ ] Negrito em pontos-chave (com moderação)
- [ ] Subtítulos que permitem escaneamento
- [ ] Contraste visual adequado
- [ ] Blocos de texto quebrados

### 2.3 Consistência Interna

**Critério:** Informações não se contradizem.

- [ ] Números são consistentes em toda peça
- [ ] Promessas são coerentes entre si
- [ ] Tom de voz é uniforme
- [ ] Terminologia é padronizada
- [ ] Datas e prazos estão corretos e consistentes
- [ ] Nome do produto/serviço está uniforme

## Gate 3: Elementos Persuasivos

### 3.1 Proposta de Valor

**Critério:** O valor é claro e convincente.

- [ ] Benefício principal está explícito

- [ ] Valor justifica o investimento
- [ ] Promessa é crível e alcançável

- [ ] Credenciais relevantes mencionadas
- [ ] Logos/certificações quando aplicável
- [ ] Histórico ou experiência demonstrada

## Gate 4: Gramática e Formatação

### 4.1 Correção Gramatical

**Critério:** Zero erros de português.

- [ ] Ortografia verificada (corretor automático)
- [ ] Concordância verbal correta
- [ ] Concordância nominal correta
- [ ] Pontuação adequada
- [ ] Acentuação correta
- [ ] Crase usada corretamente
- [ ] Revisão humana realizada

**Verificações Específicas:**

- [ ] "Mais" vs "Mas"
- [ ] "Há" (tempo) vs "A" (distância/futuro)
- [ ] "Por que" vs "Porque" vs "Porquê"
- [ ] "Onde" vs "Aonde"
- [ ] Vírgula antes de "mas"
- [ ] Plural de palavras compostas

### 4.2 Estilo e Tom

**Critério:** Tom consistente e apropriado.

- [ ] Tom alinhado com a marca
- [ ] Nível de formalidade adequado ao público
- [ ] Voz ativa predominante
- [ ] Frases diretas e concisas
- [ ] Palavras desnecessárias removidas
- [ ] Repetições intencionais (ênfase) vs. acidentais

- [ ] Cabeçalhos hierárquicos

## Gate 5: Chamada para Ação (CTA)

### 5.1 Clareza do CTA

**Critério:** O leitor sabe exatamente o que fazer.

- [ ] CTA principal é único e claro
- [ ] Verbo de ação específico
- [ ] Próximo passo é óbvio
- [ ] Benefício implícito no CTA
- [ ] Não há ambiguidade

**CTA Principal:** _________________________________

### 5.2 Visibilidade do CTA

**Critério:** CTA é facilmente encontrado.

- [ ] CTA visualmente destacado
- [ ] Posicionamento estratégico
- [ ] Repetido quando apropriado
- [ ] Contraste suficiente
- [ ] Tamanho adequado (botão)

### 5.3 Fricção Minimizada

**Critério:** Barreiras para ação são minimizadas.

- [ ] Formulário simples (mínimo de campos)
- [ ] Processo claro e curto
- [ ] Opções de pagamento adequadas
- [ ] Garantia visível próxima ao CTA

- [ ] Tempo estimado informado

## VALIDAÇÃO: BANCO DE 4 PERNAS (AWAI)

Todo copy deve se sustentar em 4 pernas. Se faltar uma, a copy "cai".

- [ ] **Perna 1: Benefício forte e irresistível** — O leitor QUER isso?
- [ ] **Perna 2: Track record demonstrável** — Tem PROVA de resultado?
- [ ] **Perna 3: Credibilidade** — O leitor CONFIA na fonte?
- [ ] **Perna 4: Boa ideia (Big Idea)** — É DIFERENTE de tudo que já viram?

> **REGRA:** Se qualquer perna estiver ausente, a copy NÃO está pronta para publicação. Fortaleça a perna fraca antes de prosseguir.
