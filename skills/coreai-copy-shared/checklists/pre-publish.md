# Checklist Pré-Publicação

Este é o último checkpoint antes de qualquer copy ir ao ar. Execute cada item meticulosamente. Um único erro pode comprometer toda a campanha.

**Regra:** Não publique até que TODOS os itens críticos estejam marcados.

---

## Seção 1: Revisão de Conteúdo

### 1.1 Revisão Textual Final

**Última verificação do texto antes de publicar.**

- [ ] Leitura completa em voz alta realizada
- [ ] Segunda pessoa revisou o texto
- [ ] Corretor ortográfico executado
- [ ] Nomes próprios verificados (pessoas, empresas, produtos)
- [ ] Números e estatísticas confirmados com fonte
- [ ] Datas, horários e fusos verificados
- [ ] Preços e valores corretos
- [ ] Moeda correta (R$, US$, etc.)
- [ ] Telefones e contatos funcionando

**Campos de Verificação:**

| Item | Valor | Verificado |
|------|-------|------------|
| Preço principal | R$ _______ | [ ] |
| Prazo de oferta | __________ | [ ] |
| Data limite | __________ | [ ] |
| Telefone | __________ | [ ] |
| Email | __________ | [ ] |

### 1.2 Consistência com Aprovações

- [ ] Versão final corresponde ao aprovado
- [ ] Alterações pós-aprovação foram re-aprovadas
- [ ] Cliente/stakeholder deu OK final
- [ ] Jurídico/compliance aprovou (se necessário)
- [ ] Não há texto placeholder remanescente
- [ ] Lorem Ipsum removido
- [ ] [INSERIR AQUI] substituído

### 1.3 Alinhamento de Campanha

- [ ] Copy alinha com outras peças da campanha
- [ ] Mensagem consistente em todos os canais
- [ ] Datas de início/fim sincronizadas
- [ ] Ofertas são as mesmas em todas as peças
- [ ] UTMs são únicos e rastreáveis

## Seção 5: Legal e Compliance

### 5.1 Requisitos Legais

- [ ] Termos de uso linkados/acessíveis
- [ ] Política de privacidade linkada
- [ ] Política de cookies (se aplicável)
- [ ] Disclaimer necessário está visível
- [ ] Aviso de publicidade (se conteúdo patrocinado)
- [ ] Idade mínima verificada (se produto restrito)
- [ ] Restrições geográficas informadas

### 5.2 LGPD/GDPR Compliance

- [ ] Consent para cookies implementado
- [ ] Opt-in claro para newsletter
- [ ] Checkbox de termos não pré-marcado
- [ ] Dados coletados são os mínimos necessários
- [ ] Base legal para coleta identificada
- [ ] Link para descadastramento presente
- [ ] Formulário solicita apenas dados necessários

### 5.3 Propriedade Intelectual

- [ ] Marcas registradas com ® ou ™ onde necessário
- [ ] Citações têm fonte
- [ ] Imagens licenciadas ou próprias
- [ ] Música/áudio licenciado
- [ ] Fontes licenciadas para web
- [ ] Conteúdo de terceiros autorizado

### 5.4 Claims e Promessas

- [ ] Promessas podem ser cumpridas
- [ ] Resultados não são garantidos indevidamente
- [ ] "Típico" ou "pode variar" onde necessário
- [ ] Estudos citados são verificáveis
- [ ] Testemunhos são reais e autorizados
- [ ] Antes/depois são reais (não simulados)

## Protocolo de Emergência Pós-Publicação

Se algo der errado após publicar:

### Severidade Alta (Reverter Imediatamente)
- Link de compra quebrado
- Preço errado
- Informação legal incorreta
- Formulário não funciona
- Página não carrega

**Ação:** Rollback imediato + notificar stakeholders

### Severidade Média (Corrigir em 1h)
- Typo em área visível
- Imagem quebrada
- Tracking incorreto
- Mobile com problema

**Ação:** Hotfix + monitorar

### Severidade Baixa (Corrigir em 24h)
- Typo em área menos visível
- Otimização de performance
- Ajuste de copy menor

**Ação:** Agendar correção
