# Template: Close Script (Script de Fechamento)

```yaml
name: close-script-template
description: Template para scripts e sequências de fechamento de vendas
output_type: close-script
version: 1.0
category: criacao
primary_agent: "@closer"
contexts: [call, webinar, presencial, whatsapp]
```

## Instruções de Uso

1. Este template foca exclusivamente no MOMENTO DE FECHAR
2. Preencha os placeholders {PLACEHOLDER}
3. Adapte para o contexto (call, webinar, presencial, WhatsApp)
4. Pratique as transições até ficarem naturais
5. Tenha as respostas de objeções decoradas

---

## ESTRUTURA DO CLOSE

<!-- O close não é um "momento". É uma sequência de micro-compromissos que leva à decisão final. -->

```
FASE 1: TRANSIÇÃO PARA CLOSE
FASE 2: STACK DE VALOR RECAPITULADO
FASE 3: ANCORAGEM DE PREÇO
FASE 4: REVELAÇÃO DE PREÇO
FASE 5: GARANTIA
FASE 6: URGÊNCIA / ESCASSEZ
FASE 7: PERGUNTA DE FECHAMENTO
FASE 8: TRATAMENTO DE "PRECISO PENSAR"
FASE 9: FOLLOW-UP SEQUENCIAL (24h / 48h / 72h)
```

---

## FASE 1: TRANSIÇÃO PARA CLOSE

<!-- A transição deve ser suave. O lead NÃO pode sentir que "agora vem a venda". -->

### Template A: Transição por Resumo

```
"Então, {NOME}, vou fazer um resumo do que conversamos.

Você me disse que está em {SITUAÇÃO ATUAL DO LEAD}.

Que já tentou {O QUE ELE TENTOU ANTES}.

E que seu objetivo é {RESULTADO DESEJADO — nas palavras DELE}.

Correto?"

[ESPERAR CONFIRMAÇÃO]

"Ótimo. Então deixa eu te mostrar como chegar lá."

<!-- Use EXATAMENTE as palavras que o lead usou. Isso cria espelhamento e confiança. -->
```

### Template B: Transição por Permissão

```
"Com base em tudo que você me contou...

Eu tenho uma proposta que acredito que resolve isso pra você.

Posso te apresentar?"

[ESPERAR "SIM"]

<!-- Pedir permissão antes de apresentar gera micro-compromisso. Quando ele diz "sim", está aberto. -->
```

### Template C: Transição por Bifurcação

```
"Nesse momento, você tem basicamente dois caminhos:

1. Continuar fazendo {O QUE ELE FAZ HOJE} e esperar resultados diferentes

2. Ter um método comprovado pra chegar em {RESULTADO DELE}

Vou te mostrar o caminho 2."
```

## FASE 3: ANCORAGEM DE PREÇO

<!-- A ancoragem prepara o cérebro para avaliar o preço real como "barato" em comparação. -->

### Template de Ancoragem

```
"Agora, se você fosse contratar {ALTERNATIVA 1} pra ter esses resultados...

Pagaria pelo menos R$ {VALOR_ALTO_1} por {PERÍODO}.

Se contratasse {ALTERNATIVA 2}, investiria R$ {VALOR_ALTO_2}.

Se tentasse fazer sozinho, gastaria {TEMPO} e provavelmente
R$ {VALOR} em tentativa e erro.

Então o valor justo seria pelo menos R$ {VALOR_JUSTO}."

<!-- Âncoras devem ser reais e verificáveis. Não invente. -->
```

### Ancoragem por Custo da Inação

```
"Você me disse que {PROBLEMA} está te custando
R$ {VALOR_MENSAL} por mês.

Em 12 meses, são R$ {VALOR_ANUAL} que você perde
sem resolver isso.

O {NOME DO PRODUTO} custa uma fração disso.

E resolve o problema de vez."
```

## FASE 4: REVELAÇÃO DE PREÇO

<!-- Nunca peça desculpas pelo preço. Apresente com confiança e silêncio. -->

### Template de Revelação

```
"Seu investimento total no {NOME DO PRODUTO} é:

R$ {PREÇO}

Ou {NÚMERO}x de R$ {PARCELA} no cartão."

[PAUSA — 3 SEGUNDOS DE SILÊNCIO]

<!-- Não justifique. Não fale "é pouco". Não encha de palavras. Deixe o número respirar. -->

"Fazendo as contas, isso dá R$ {VALOR_DIÁRIO} por dia.

Menos que {COMPARAÇÃO — um café especial / um almoço / um uber}."
```

### Técnica do Investimento vs. Retorno

```
"E olha que interessante:

Se o {NOME DO PRODUTO} te gerar apenas {RESULTADO MÍNIMO REALISTA}...

São R$ {VALOR_RESULTADO} de retorno.

Pra um investimento de R$ {PREÇO}.

Isso é um ROI de {X}x.

E nossos clientes geralmente atingem {RESULTADO MÉDIO}, que é ainda maior."
```

## FASE 5: GARANTIA

<!-- A garantia remove a percepção de risco. Sem garantia, o preço parece mais alto. -->

### Template de Garantia

```
"E pra tirar qualquer risco da sua decisão...

Você tem {DIAS} dias de garantia incondicional.

O que significa:

→ Você entra agora
→ Acessa tudo
→ Aplica o método
→ Vê os primeiros resultados

Se em {DIAS} dias você sentir que não valeu...
Ou se simplesmente não for pra você...

Você pede reembolso.
Eu devolvo 100% do valor.
Sem perguntas, sem burocracia.

O risco é TODO meu.

Você só arrisca se NÃO tentar."
```

### Garantia Condicional (High-Ticket)

```
"Minha garantia vai além:

Se você aplicar o método por {DIAS} dias...
E não tiver {RESULTADO MÍNIMO}...

Eu continuo te acompanhando GRÁTIS até você ter.

Porque eu confio tanto no método que coloco meu tempo em jogo."
```

## FASE 6: URGÊNCIA / ESCASSEZ

<!-- Urgência deve ser REAL. Escassez falsa destrói confiança. -->

### Template de Escassez Real

```
"Preciso ser transparente com você:

{MOTIVO DA ESCASSEZ}

Opções reais:
• "{NÚMERO} vagas restantes — porque eu acompanho pessoalmente"
• "Esse preço é válido até {DATA} — depois volta para R$ {PREÇO_CHEIO}"
• "Os bônus saem em {DATA} — sem exceção"
• "Turma fecha em {DATA} — próxima só em {MÊS}"

<!-- Escolha apenas 1 escassez. Múltiplas escassezes parecem desesperadas. -->

Então se faz sentido pra você, o melhor momento é agora."
```

### Urgência por Custo de Esperar

```
"Me deixa te fazer uma conta rápida:

Cada dia que você espera, {PROBLEMA} continua te custando
R$ {CUSTO_DIÁRIO}.

Se você decidir semana que vem, são R$ {CUSTO_SEMANAL} a mais.

Se decidir mês que vem, R$ {CUSTO_MENSAL}.

A pergunta não é se você vai resolver.
É quando."
```

## FASE 7: PERGUNTA DE FECHAMENTO

<!-- A pergunta de fechamento NÃO é "quer comprar?". É uma pergunta que assume a venda. -->

### Close Direto

```
"Então, {NOME}...

Faz sentido pra você começar?"

[SILÊNCIO TOTAL — espere a resposta]

<!-- Depois da pergunta de fechamento, NUNCA fale primeiro. Silêncio é poder. -->
```

### Close Alternativo (Escolha entre opções)

```
"Perfeito, {NOME}.

Você prefere:

Opção A: À vista com {DESCONTO}% de desconto — R$ {VALOR_AVISTA}
Opção B: Parcelado em {X}x de R$ {PARCELA}

Qual funciona melhor pra você?"

<!-- As duas opções levam à compra. A pergunta não é "se", é "como". -->
```

### Close por Compromisso

```
"Deixa eu te perguntar uma coisa, {NOME}:

Em tudo que conversamos hoje...

Você acredita que o {NOME DO PRODUTO} resolve o que precisa?"

[ESPERAR "SIM"]

"E o investimento faz sentido pra você?"

[ESPERAR "SIM"]

"Então não tem motivo pra esperar, certo?

Vou te mandar o link agora."
```

### Close por Consequência

```
"O que acontece se você não fizer nada?

Daqui a 3 meses, você vai estar {PROJEÇÃO NEGATIVA}.

Ou daqui a 3 meses, você pode estar {PROJEÇÃO POSITIVA}.

A diferença é essa decisão. Agora.

Vamos?"
```

## FASE 8: TRATAMENTO DE "PRECISO PENSAR"

<!-- "Preciso pensar" NUNCA é a objeção real. Sempre tem algo por trás. -->

### Nível 1: Descobrir a Objeção Real

```
"Entendo, {NOME}. Decisão séria merece reflexão.

Mas me ajuda a entender melhor:

Quando você diz 'preciso pensar'...

É sobre...
A. O {PRODUTO} em si — se realmente funciona?
B. O investimento — se cabe no momento?
C. O timing — se é a hora certa?
D. Outra coisa?

Qual se encaixa mais?"

[ESCUTAR — a resposta revela a objeção real]
```

### Nível 2: Isolamento da Objeção

```
"Se {OBJEÇÃO QUE ELE REVELOU} não fosse uma questão...

Você entraria agora?"

[SE SIM]: "Ótimo, então vamos resolver isso juntos."
[SE NÃO]: "O que mais te preocupa?"

<!-- Continue isolando até chegar na objeção REAL -->
```

### Nível 3: Tratamento Específico

**Se for sobre DINHEIRO:**
```
"Entendo a preocupação com o investimento.

Mas me deixa te perguntar:

Quanto vai te custar NÃO resolver {PROBLEMA}?

Você me disse que perde R$ {VALOR} por mês com isso.

O {PRODUTO} se paga em {TEMPO}.

E temos a opção de {PARCELAMENTO}.

São R$ {VALOR_PARCELA}. Menos que {COMPARAÇÃO}.

E com garantia de {DIAS} dias, se não funcionar, seu dinheiro volta."
```

**Se for sobre TIMING:**
```
"Quando seria o momento 'certo' pra você?

Deixa eu ser honesto: o momento perfeito não existe.

O {NOME_CLIENTE} me disse a mesma coisa {TEMPO} atrás.

Hoje ele {RESULTADO}.

Se tivesse esperado, ainda estaria {SITUAÇÃO RUIM}.

O melhor momento foi ontem. O segundo melhor é agora."
```

**Se for sobre CONFIANÇA/CETICISMO:**
```
"É justo ter cautela, {NOME}.

Por isso mesmo existe a garantia de {DIAS} dias.

Você não precisa confiar em mim agora.

Precisa confiar que {DIAS} dias é tempo suficiente
pra testar e decidir.

Se não funcionar, devolvo seu dinheiro.

O único risco é não tentar."
```

### Último Recurso: Escada de Compromisso

```
"Vamos fazer assim, {NOME}:

Eu vou te mandar o link.

Não precisa decidir agora.

O link fica válido até {PRAZO — 24/48h}.

Você pensa com calma, e se fizer sentido, é só clicar.

Se não fizer, sem problema. Combinado?"

<!-- Isso mantém a porta aberta sem pressionar. Muitos fecham sozinhos. -->
```

## FASE 9: FOLLOW-UP SEQUENCIAL

### Follow-up 24h

```
CANAL: WhatsApp (preferencial)
TOM: Valor + lembrete suave

"{NOME}, tudo bem?

Gostei muito da nossa conversa ontem.

Inclusive, lembrei de um case que tem tudo a ver com sua situação:

{CASE OU CONTEÚDO RELEVANTE}

O link que te mandei ainda está ativo.
Se tiver alguma dúvida, estou aqui."
```

### Follow-up 48h

```
CANAL: WhatsApp
TOM: Prova social + leveza

"{NOME}!

Olha o que o {NOME_CLIENTE} mandou hoje no grupo:

{PRINT DE RESULTADO / DEPOIMENTO}

Ele entrou {TEMPO} atrás e estava na mesma situação que você.

Pensou nisso?"
```

### Follow-up 72h

```
CANAL: WhatsApp + E-mail
TOM: Escassez + respeito

"{NOME}, passando pra avisar:

{ELEMENTO DE ESCASSEZ}:

• {ESCASSEZ 1 — preço / vagas / bônus}
• Válido até {DATA/HORA}

Depois disso, {CONSEQUÊNCIA — preço volta ao normal / vagas esgotam}.

Se quiser garantir, é agora.

Se decidiu que não é o momento, respeito totalmente.
Me avisa que encerro seu arquivo."

<!-- A frase "encerro seu arquivo" gera urgência sem ser agressiva -->
```

### Follow-up 7 dias (Último)

```
CANAL: E-mail
TOM: Honesto + porta aberta

"Assunto: Fechando o ciclo

{NOME},

Faz uma semana desde nossa conversa.

Imagino que decidiu não seguir agora, e respeito isso.

Se no futuro sentir que é a hora, estarei por aqui.

Te desejo sucesso com {RESULTADO QUE ELE QUERIA}.

Abs,
{SEU_NOME}"

<!-- Esse e-mail surpreendentemente gera respostas. Muitos voltam. -->
```

## CHECKLIST DE QUALIDADE

**Antes do close:**
- [ ] Diagnóstico completo (dor, desejo, urgência, budget)
- [ ] Lead confirmou verbalmente que tem o problema
- [ ] Lead verbalizou o resultado desejado
- [ ] Prova social direcionada apresentada
- [ ] Micro-compromissos obtidos ao longo da conversa

**Durante o close:**
- [ ] Transição suave (lead não percebe que entrou no close)
- [ ] Stack de valor conectado com as dores do lead
- [ ] Ancoragem feita ANTES de revelar preço
- [ ] Preço apresentado com confiança e silêncio
- [ ] Garantia mencionada ANTES da pergunta de fechamento
- [ ] Urgência/escassez é REAL
- [ ] Pergunta de fechamento feita + SILÊNCIO

**Tratamento de objeções:**
- [ ] Objeção real descoberta (não a superficial)
- [ ] Objeção isolada ("se isso não fosse questão, entraria?")
- [ ] Tratamento sem ficar na defensiva
- [ ] Silêncio respeitado após cada resposta

**Follow-up:**
- [ ] Sequência 24h/48h/72h/7d configurada
- [ ] Cada follow-up tem valor (não só cobrança)
- [ ] Tom evolui de valor → prova social → escassez → encerramento
- [ ] CRM atualizado com status e próximo passo
