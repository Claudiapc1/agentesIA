# Template: Warm Webinar Script (Script de Webinar para Audiência Quente)

```yaml
name: warm-webinar-script-template
description: Template para scripts de webinar direcionados a audiências quentes que já conhecem o apresentador
output_type: webinar-script
version: 1.0
category: criacao
primary_agent: "@copywriter"
audience: warm (já conhece o apresentador)
duration: 60-90 minutos
```

## Instruções de Uso

1. Este template é para audiência QUENTE (já segue, já comprou algo, já interagiu)
2. Preencha os placeholders {PLACEHOLDER}
3. Adapte o tom para reconhecer a relação existente com a audiência
4. Leia em voz alta para verificar timing (60-90 min total)
5. Prepare slides de apoio para cada seção

---

## DIFERENÇA: WEBINAR QUENTE vs. FRIO

<!-- Audiência quente já confia em você. Não precisa provar credenciais. Precisa aprofundar a conexão e apresentar a oferta como evolução natural. -->

```
WEBINAR FRIO:                      WEBINAR QUENTE:
- Precisa provar quem é            - Já sabe quem você é
- Construir confiança do zero      - Confiança já existe
- Mais tempo em prova social       - Mais tempo em conteúdo
- Tom formal/educativo             - Tom conversacional/íntimo
- Close mais estruturado           - Close mais natural
- 50% conteúdo / 50% venda        - 60% conteúdo / 40% venda
```

## SEÇÃO 6: Q&A GUIDELINES (70:00 - 90:00)

<!-- O Q&A é uma oportunidade de close. Cada resposta deve quebrar objeções e reforçar a oferta. -->

### Regras do Q&A

```
1. PRIORIZE perguntas que são objeções disfarçadas
2. RESPONDA sempre conectando com o produto
3. RECONHEÇA quem está comprando no chat
4. MANTENHA urgência viva (lembrar bônus, vagas, etc.)
5. FECHE novamente ao final do Q&A
```

## DICAS PARA WEBINAR QUENTE

```
1. USE NOMES da audiência durante o webinar (gera pertencimento)
2. REFERENCIE conteúdos anteriores seus ("como falei naquele post...")
3. FAÇA PIADAS INTERNAS que só quem te acompanha entende
4. MOSTRE BASTIDORES que não mostra publicamente
5. TRATE como conversa entre amigos, não palestra
6. OFEREÇA CONDIÇÃO que só essa audiência tem acesso
7. RECONHEÇA PUBLICAMENTE quem compra durante o webinar
8. NÃO SE DESCULPE por vender — sua audiência espera ofertas de você
```

## CHECKLIST DE QUALIDADE

**Antes do webinar:**
- [ ] Script lido em voz alta (timing verificado: 60-90 min)
- [ ] Slides preparados e testados
- [ ] Link de compra funcionando
- [ ] Bônus exclusivos configurados
- [ ] E-mail de lembrete enviado (1h e 15min antes)
- [ ] Chat/interação testados
- [ ] Plano B se der problema técnico

**Abertura:**
- [ ] Reconhecimento de nomes da audiência
- [ ] Promessa clara do que vão aprender
- [ ] Compromisso de ficar até o final
- [ ] Tom conversacional (não palestra)

**Conteúdo:**
- [ ] 3 segredos entregam valor real e aplicável
- [ ] Cada segredo planta semente para a oferta
- [ ] Cases/exemplos são de pessoas que a audiência conhece ou se identifica
- [ ] Interação via chat mantida ao longo do webinar

**Close:**
- [ ] Transição suave e transparente para oferta
- [ ] Stack de valor conectado com as dores da audiência
- [ ] Preço ancorado adequadamente
- [ ] Garantia clara e confiante
- [ ] Escassez/urgência real (bônus ao vivo, vagas, prazo)
- [ ] Compradores reconhecidos no chat

**Q&A:**
- [ ] Perguntas-objeção priorizadas
- [ ] Cada resposta conecta com o produto
- [ ] Urgência mantida até o final
- [ ] Close final feito antes de encerrar
