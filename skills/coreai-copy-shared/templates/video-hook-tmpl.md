# Template: Video Hook (Ganchos de Abertura para Vídeo)

```yaml
name: video-hook-template
description: Template para ganchos de abertura de vídeo (3-60 segundos)
output_type: video-hook
version: 1.0
category: criacao
primary_agent: "@copywriter"
duration: 3-60 segundos
formats: [reels, shorts, tiktok, youtube, vsl, ads]
```

## Instruções de Uso

1. Identifique o tipo de hook adequado ao objetivo
2. Preencha os placeholders {PLACEHOLDER}
3. Crie no mínimo 3 variações por peça
4. Leia em voz alta cronometrando o tempo
5. Teste visual + textual combinados

---

## ANATOMIA DE UM VIDEO HOOK

<!-- O hook é a peça mais importante de qualquer vídeo. Determine se 80%+ da audiência fica ou sai. -->

```
ESTRUTURA EM 3 CAMADAS:

Camada 1: PRIMEIROS 3 SEGUNDOS (texto + visual)
→ Interrompe o padrão mental / para o scroll
→ É o "headline" do vídeo

Camada 2: LOOP ABERTO (segundos 3-15)
→ Cria curiosidade que só se resolve assistindo
→ Promete algo específico

Camada 3: TRANSIÇÃO PARA CONTEÚDO (segundos 15-60)
→ Conecta o hook com o corpo do vídeo
→ Mantém o momentum da atenção
```

## TIPO 1: HOOK DE CURIOSIDADE

### Para: Conteúdo educativo, revelações, insights

**Template — Primeiros 3 Segundos:**
```
[TEXTO NA TELA]: "{FRASE CURTA QUE GERA CURIOSIDADE}"

<!-- Máximo 8 palavras no texto. A frase deve ser lida em menos de 2 segundos. -->

[VISUAL]: {AÇÃO DO APRESENTADOR — olhar direto pra câmera, gesto de "para"}

[FALA]: "{FRASE DE ABERTURA FALADA}"
```

**Template Completo:**
```
(0:00-0:03) INTERRUPÇÃO:
[TEXTO]: "{PERGUNTA OU AFIRMAÇÃO CHOCANTE}"
[FALA]: "Ninguém te conta isso sobre {TÓPICO}..."

<!-- Exemplo: "O segredo que os gurus escondem" / "Isso muda tudo sobre {TÓPICO}" -->

(0:03-0:10) LOOP ABERTO:
[FALA]: "Existe {UM CONCEITO/MÉTODO/SEGREDO} que {PORCENTAGEM}% das pessoas
que {AÇÃO DO AVATAR} não conhecem.

E quando eu descobri isso, {RESULTADO QUE TIVE}.

Nos próximos {NÚMERO} segundos, eu vou te mostrar exatamente {O QUE VAI REVELAR}."

(0:10-0:20) TRANSIÇÃO:
[FALA]: "Mas antes, você precisa entender {CONTEXTO NECESSÁRIO}...

{PRIMEIRA FRASE DO CONTEÚDO}"

<!-- A transição deve ser imperceptível. O espectador nem percebe que o hook acabou. -->
```

**Variação A:**
```
"Você sabia que {FATO CONTRA-INTUITIVO}?"
```

**Variação B:**
```
"Se você {SITUAÇÃO DO AVATAR}, precisa ver isso até o final."
```

**Variação C:**
```
"Eu levei {TEMPO} pra descobrir o que vou te contar em {SEGUNDOS} segundos."
```

## TIPO 2: HOOK DE POLÊMICA

### Para: Posicionamento, debates, opiniões fortes

**Template Completo:**
```
(0:00-0:03) INTERRUPÇÃO:
[TEXTO]: "{OPINIÃO CONTRÁRIA AO SENSO COMUM}"
[FALA]: "{AFIRMAÇÃO PROVOCATIVA}"

<!-- Exemplo: "Funis de venda não funcionam." / "Seguidores são inúteis." -->
<!-- CUIDADO: polêmica com fundamento, não clickbait vazio -->

(0:03-0:15) LOOP ABERTO:
[FALA]: "Eu sei que isso soa {ADJETIVO — absurdo/radical/diferente}.

Mas antes de me xingar nos comentários...

Deixa eu te explicar por que {REFORMULAÇÃO DA POLÊMICA COM NUANCE}.

Porque quando eu entendi isso, {RESULTADO CONCRETO}."

(0:15-0:30) TRANSIÇÃO:
[FALA]: "O problema com {CRENÇA COMUM} é que {RAZÃO}.

Veja bem..."

<!-- A transição deve suavizar a polêmica e iniciar a argumentação lógica -->
```

**Variação A:**
```
"Pare de {AÇÃO QUE TODOS FAZEM}. Isso está destruindo seu {RESULTADO}."
```

**Variação B:**
```
"{AFIRMAÇÃO POLÊMICA}. E eu tenho provas."
```

**Variação C:**
```
"Tudo que te ensinaram sobre {TÓPICO} está errado. Vou provar em {SEGUNDOS} segundos."
```

## TIPO 3: HOOK DE RESULTADO

### Para: Prova social, cases, transformações

**Template Completo:**
```
(0:00-0:03) INTERRUPÇÃO:
[TEXTO]: "{NÚMERO IMPRESSIONANTE + CONTEXTO}"
[FALA]: "{RESULTADO CONCRETO COM NÚMEROS}"

<!-- Exemplo: "R$ 127.000 em 30 dias" / "De 0 a 10.000 seguidores em 2 semanas" -->
<!-- Use números reais. Resultados específicos > genéricos. -->

(0:03-0:15) LOOP ABERTO:
[FALA]: "E não foi sorte.

{CONTEXTO QUE HUMANIZA — de onde partiu, o que tentou antes}

Tudo mudou quando eu {AÇÃO ESPECÍFICA QUE GEROU O RESULTADO}.

E o mais surpreendente? {DETALHE QUE GERA CURIOSIDADE}."

(0:15-0:30) TRANSIÇÃO:
[FALA]: "Vou te mostrar os {NÚMERO} passos exatos que usei.

Passo 1..."

<!-- Transição direta para o conteúdo. Sem enrolação após promessa de resultado. -->
```

**Variação A:**
```
"Isso aqui me gerou R$ {VALOR} em {TEMPO}. E vou te mostrar como."
```

**Variação B:**
```
"{NOME DO CLIENTE} fez {RESULTADO} em {TEMPO}. Quer saber o que ela fez diferente?"
```

**Variação C:**
```
"Em {DATA} eu estava {SITUAÇÃO RUIM}. Hoje, {SITUAÇÃO BOA}. Isso é o que mudou."
```

## TIPO 4: HOOK DE HISTÓRIA

### Para: Storytelling, conexão emocional, narrativas

**Template Completo:**
```
(0:00-0:03) INTERRUPÇÃO:
[TEXTO]: "{FRASE INTRIGANTE DA HISTÓRIA}"
[VISUAL]: {CENA OU EXPRESSÃO que gere curiosidade}

<!-- Exemplo: "Eu quase desisti de tudo" / "O dia que perdi R$ 50.000" -->
<!-- Histórias que começam no clímax prendem mais. -->

(0:03-0:15) LOOP ABERTO:
[FALA]: "Lembro como se fosse ontem.

Era {DATA/PERÍODO}.

Eu estava {SITUAÇÃO VISUAL E EMOCIONAL}.

{DETALHE SENSORIAL — o que via, ouvia, sentia}

E foi nesse momento que {EVENTO CATALISADOR}."

(0:15-0:45) DESENVOLVIMENTO:
[FALA]: "O que aconteceu depois mudou tudo.

{CONTINUAR A HISTÓRIA...}

Mas o ponto não é a história em si.

É o que eu aprendi com ela.

E é isso que quero te mostrar agora."

<!-- A história é o veículo. A lição é o destino. Nunca conte história sem propósito. -->
```

**Variação A:**
```
"Dia {DATA}. {HORA}. Eu recebo uma mensagem que mudou tudo..."
```

**Variação B:**
```
"Isso aconteceu quando eu tinha {IDADE/CONTEXTO} e eu nunca esqueci."
```

**Variação C:**
```
"Ninguém sabe disso, mas {REVELAÇÃO PESSOAL}..."
```

[TEXTO]: "{NÚMERO} {COISAS} que {PROMESSA}"

Se você só aplicar esse, já vai ver diferença em {TEMPO}.

{EXPLICAÇÃO BREVE}..."

<!-- Vá direto para o conteúdo. Sem enrolação. -->
```

```

**Variação B:**
```
"Se você {SITUAÇÃO}, salva esse vídeo. São {NÚMERO} dicas em {TEMPO}."
```

**Variação C:**
```
"O framework de {NÚMERO} passos que uso pra {RESULTADO}. Toda semana."

## SUGESTÕES VISUAIS POR TIPO

### Curiosidade
```
- Expressão de "vou te contar um segredo"
- Gesto de "para tudo"
- Zoom lento na câmera
- Texto aparecendo letra por letra
```

### Polêmica
```
- Expressão séria / convicta
- Gesto de "não" ou "errado"
- Fundo vermelho ou texto vermelho
- Corte seco para câmera frontal
```

### Resultado
```
- Mostrar print de resultado / dashboard
- Gesto de "dá uma olhada nisso"
- Screenshot ou screen recording
- Before/after visual
```

### História
```
- Olhar distante (memória)
- Cena de transição (B-roll)
- Música de fundo sutil
- Iluminação mais suave
```

### Lista/Framework
```
- Contagem visual (dedos ou texto)
- Quadro branco / lousa
- Texto aparecendo por etapas
- Energia alta, ritmo rápido
```

## REGRAS DOS PRIMEIROS 3 SEGUNDOS

<!-- Estas regras são inegociáveis. Os 3 primeiros segundos determinam tudo. -->

```
1. TEXTO NA TELA é obrigatório (muita gente assiste sem som)
2. Máximo 8 palavras no texto
3. A fala deve começar IMEDIATAMENTE (sem "oi gente", sem intro)
4. Algo deve se MOVER (corte, zoom, gesto, texto animado)
5. A promessa deve ser ESPECÍFICA (nunca genérica)
```

### O que NUNCA fazer nos primeiros 3 segundos:
```
❌ "Oi pessoal, tudo bem?"
❌ "Meu nome é [NOME] e hoje..."
❌ "Nesse vídeo eu vou..."
❌ Introdução do canal/marca
❌ Logo animada
❌ Música de intro
```

### O que SEMPRE fazer nos primeiros 3 segundos:
```
✅ Começar pelo conteúdo
✅ Usar texto visual
✅ Falar uma frase de impacto
✅ Criar movimento visual
✅ Gerar curiosidade imediata
```

```

PLATAFORMA: Instagram

---

[TEXTO NA TELA]: "De 2% pra 8% de conversão"

[VISUAL]: Print da landing page com métricas, zoom no headline

---

HOOK VARIAÇÃO 2 — Lista

[TEXTO NA TELA]: "3 erros de headline"
[FALA]: "3 erros de headline que estão matando sua conversão.
O terceiro é o pior e 90% dos copywriters comete."
[VISUAL]: Câmera frontal, expressão séria, 3 dedos

---

Deixa eu te provar."

com número específico costuma ter melhor retenção em conteúdo

## CHECKLIST DE QUALIDADE

**Primeiros 3 segundos:**
- [ ] Texto na tela presente e com menos de 8 palavras
- [ ] Fala começa imediatamente (sem saudação)
- [ ] Movimento visual (corte, zoom, gesto)
- [ ] Promessa específica (não genérica)

**Loop aberto (3-15 segundos):**
- [ ] Curiosidade criada que só se resolve assistindo
- [ ] Tempo de vídeo mencionado (gera compromisso)
- [ ] Objeções iniciais quebradas

**Transição (15-60 segundos):**
- [ ] Conexão natural com o conteúdo principal
- [ ] Momentum de atenção mantido
- [ ] Sem "dead air" ou pausas longas

**Variações:**
- [ ] 3 hooks criados por peça (mínimo)
- [ ] Tipos diferentes de hook nas variações
- [ ] Sugestão visual para cada variação
- [ ] Recomendação de qual testar primeiro
- [ ] Cada hook lido em voz alta e cronometrado
