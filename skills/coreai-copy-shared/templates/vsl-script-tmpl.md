# Template: VSL (Video Sales Letter) Script

```yaml
name: vsl-script-template
description: Template completo para scripts de VSL com timing detalhado
output_type: video-script
version: 1.0
estimated_duration: 12-20 minutos
```

## Instruções de Uso

1. Preencha todos os placeholders [PLACEHOLDER]
2. Respeite os tempos sugeridos para cada seção
3. Leia em voz alta para testar fluidez
4. Grave versão teste antes da produção final
5. Adicione indicações visuais entre parênteses

---

## ESTRUTURA GERAL

```
TOTAL: 12-20 minutos

00:00-00:30  → HOOK (Gancho)
00:30-02:00  → PROBLEM (Problema)
02:00-05:00  → STORY (História)
05:00-08:00  → SOLUTION (Solução)
08:00-10:00  → PROOF (Prova)
10:00-14:00  → OFFER (Oferta)
14:00-15:00+ → CLOSE (Fechamento)
```

## INDICAÇÕES TÉCNICAS

### Elementos Visuais por Seção
```
HOOK:
- Texto grande em tela
- Cortes rápidos
- Movimento

PROBLEMA:
- Lista de sintomas
- Estatísticas
- Imagens de frustração

HISTÓRIA:
- Fotos do apresentador
- Antes/Depois
- Linha do tempo

SOLUÇÃO:
- Diagrama do método
- Logo do produto
- Screenshots/Demos

PROVA:
- Fotos de clientes
- Depoimentos em vídeo
- Números em destaque

OFERTA:
- Stack visual
- Preço em destaque
- Timer (se aplicável)

FECHAMENTO:
- Botão de CTA
- Garantia visual
- Setas/Direcionamento
```

### Dicas de Gravação
```
- Fale olhando para a câmera (conexão)
- Varie o tom de voz (emoção)
- Use pausas estratégicas (ênfase)
- Gesticule naturalmente (energia)
- Mantenha ritmo dinâmico (atenção)
```
