## Instruções de Uso

1. Escolha a categoria que melhor se alinha ao seu objetivo
2. Selecione a fórmula mais apropriada para seu contexto
3. Preencha os placeholders [PLACEHOLDER]
4. Crie 5-10 variações para teste A/B
5. Valide com seu avatar antes de finalizar

## ANATOMIA DE UMA HEADLINE EFICAZ

```
HEADLINE = PROMESSA + ESPECIFICIDADE + GATILHO EMOCIONAL

Elementos que funcionam:
• NÚMEROS: Criam expectativa concreta
• TEMPO: Estabelecem prazo realista
• BENEFÍCIO: O que a pessoa ganha
• OBJEÇÃO: O que ela NÃO precisa fazer/ter
• CURIOSIDADE: Algo que ela quer saber
```

## CHECKLIST DE HEADLINE

Antes de finalizar sua headline, verifique:

**Clareza:**
- [ ] É possível entender em 3 segundos?
- [ ] O benefício está claro?
- [ ] Não há ambiguidade?

**Relevância:**
- [ ] Fala diretamente com o avatar?
- [ ] Aborda uma dor/desejo real?
- [ ] Está na linguagem do público?

**Especificidade:**
- [ ] Tem números ou tempo?
- [ ] O resultado é mensurável?
- [ ] É crível e realista?

**Emoção:**
- [ ] Desperta curiosidade?
- [ ] Cria desejo ou urgência?
- [ ] Conecta emocionalmente?

**Diferenciação:**
- [ ] Se destaca da concorrência?
- [ ] Tem um ângulo único?
- [ ] Não é genérica demais?

## PROCESSO DE CRIAÇÃO

### Passo 1: Brainstorm
```
- Escreva 10-20 variações sem julgamento
- Use diferentes fórmulas
- Misture categorias
```

### Passo 2: Seleção
```
- Escolha as 5 melhores
- Aplique o checklist
- Refine cada uma
```

### Passo 3: Teste
```
- Use em A/B test
- Meça taxa de clique/abertura
- Identifique padrões que funcionam
```

### Passo 4: Iteração
```
- Analise vencedores
- Entenda por que funcionaram
- Crie variações dos vencedores
```
