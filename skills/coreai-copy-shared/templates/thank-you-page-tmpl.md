# Template: Thank You Page (Página de Obrigado)

```yaml
name: thank-you-page-template
description: Template para páginas de confirmação pós-compra ou pós-opt-in
output_type: thank-you-page
version: 1.0
category: criacao
primary_agent: "@copywriter"
page_types: [pos-compra, pos-opt-in, pos-cadastro, pos-agendamento]
```

## Instruções de Uso

1. Identifique o tipo de Thank You Page (pós-compra ou pós-opt-in)
2. Preencha os placeholders {PLACEHOLDER}
3. Adapte o tom para o momento emocional do cliente
4. Configure os elementos de maximização (order bump, upsell tease)
5. Teste todos os links e redirecionamentos

---

## TIPOS DE THANK YOU PAGE

<!-- A Thank You Page não é apenas confirmação — é uma das páginas com maior taxa de atenção do funil -->

```
TIPO 1: Pós-Opt-in (Lead Magnet / Material Gratuito)
→ Objetivo: confirmar + direcionar para próximo passo + aquecer

TIPO 2: Pós-Compra (Produto / Serviço)
→ Objetivo: confirmar + reduzir remorso + maximizar valor

TIPO 3: Pós-Agendamento (Call / Consulta)
→ Objetivo: confirmar + preparar + reduzir no-show

TIPO 4: Pós-Cadastro (Webinar / Evento)
→ Objetivo: confirmar + gerar antecipação + aumentar presença
```

## ESTRUTURA COMPLETA — TIPO 1: PÓS-OPT-IN

### Seção 1: Headline de Confirmação

<!-- A headline deve confirmar a ação e reforçar que foi uma boa decisão -->

```
{EMOJI DE CONFIRMAÇÃO} {HEADLINE DE CONFIRMAÇÃO}

Opções de headline:
• "Pronto! Seu {MATERIAL} está a caminho!"
• "Excelente decisão, {NOME}! Confira seu e-mail."
• "Parabéns! Você deu o primeiro passo para {RESULTADO}."
• "{MATERIAL} enviado com sucesso!"
```

**Template:**
```
✅ {HEADLINE — confirma a ação realizada}

{SUBHEADLINE — próximo passo imediato}

<!-- Exemplo: "Enviamos o e-book para seu e-mail. Confira sua caixa de entrada (e o spam também)." -->
```

---

### Seção 2: Mensagem de Reforço

<!-- Reforce que a pessoa tomou a decisão certa. Reduza qualquer atrito pós-ação. -->

```
{MENSAGEM DE VALIDAÇÃO}

Você acabou de {AÇÃO QUE A PESSOA FEZ} e isso te coloca à frente de
{PORCENTAGEM}% das pessoas que {COMPORTAMENTO COMUM DO AVATAR}.

{FRASE QUE CONECTA O MATERIAL COM O RESULTADO DESEJADO}

<!-- Exemplo: "Ao baixar esse guia, você já está um passo à frente dos 90% de empreendedores que tentam fazer tudo sozinhos." -->
```

---

### Seção 3: Próximos Passos

<!-- Diga exatamente o que a pessoa precisa fazer agora. Clareza = confiança. -->

```
📋 Seus próximos passos:

PASSO 1: {AÇÃO IMEDIATA}
→ {INSTRUÇÃO DETALHADA}
<!-- Exemplo: "Abra seu e-mail e clique no link para acessar o material." -->

PASSO 2: {AÇÃO DE CONSUMO}
→ {INSTRUÇÃO DETALHADA}
<!-- Exemplo: "Leia as páginas 3-7 primeiro — ali está o framework completo." -->

PASSO 3: {AÇÃO DE APLICAÇÃO}
→ {INSTRUÇÃO DETALHADA}
<!-- Exemplo: "Aplique o checklist na página 12 no seu próximo conteúdo." -->
```

---

### Seção 4: Order Bump / Upsell Tease

<!-- Este é o momento de apresentar uma oferta complementar. A pessoa está com atenção máxima. -->

```
⚡ ENQUANTO VOCÊ ESPERA...

{HEADLINE DA OFERTA COMPLEMENTAR}

{DESCRIÇÃO BREVE — 2-3 frases que conectam o material gratuito com a oferta paga}

<!-- Exemplo: "No guia gratuito, você aprendeu os 5 frameworks. Mas existe um atalho: nosso treinamento de 2h onde eu aplico cada framework ao vivo, na sua frente." -->

O que você recebe:
• {BENEFÍCIO 1}
• {BENEFÍCIO 2}
• {BENEFÍCIO 3}

{PREÇO ESPECIAL — válido só nesta página}

De R$ {PREÇO_ORIGINAL} por apenas R$ {PREÇO_ESPECIAL}

<!-- Oferta deve ser complementar, não substituta do material gratuito -->

[{CTA — BOTÃO}]
```

---

### Seção 5: Expectativa de Entrega

<!-- Elimine ansiedade. Diga quando e como o material chega. -->

```
📬 Informações de entrega:

• {COMO VAI RECEBER} (e-mail, WhatsApp, área de membros)
• {PRAZO DE ENTREGA} (instantâneo, até 5 minutos, até 24h)
• {O QUE FAZER SE NÃO RECEBER} (verificar spam, contatar suporte)

Enviamos para: {EMAIL_INFORMADO}

Não recebeu? {LINK_DE_SUPORTE} ou envie e-mail para {EMAIL_SUPORTE}
```

## CHECKLIST DE QUALIDADE

**Estrutura:**
- [ ] Headline de confirmação clara e positiva
- [ ] Mensagem de reforço/validação da decisão
- [ ] Próximos passos numerados e específicos
- [ ] Expectativa de entrega definida (quando e como)
- [ ] Informações de suporte visíveis

**Maximização:**
- [ ] Order bump ou upsell coerente com a ação anterior
- [ ] Oferta complementar (não substituta)
- [ ] Preço especial "só nesta página" configurado
- [ ] Elemento de comunidade presente

**Técnico:**
- [ ] Todos os links funcionando
- [ ] E-mail de confirmação configurado para disparar
- [ ] Pixel de conversão instalado na página
- [ ] Redirecionamento automático configurado (se aplicável)
- [ ] Responsivo para mobile
- [ ] Calendar links funcionando (pós-agendamento)

**Emocional:**
- [ ] Tom celebratório e acolhedor
- [ ] Remorso de compra antecipado e tratado
- [ ] Urgência natural (sem pressão artificial neste momento)
- [ ] Pessoa sabe exatamente o que fazer agora
