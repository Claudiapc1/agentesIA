# Template: Testimonial Request (Pedido de Depoimentos)

```yaml
name: testimonial-request-template
description: Template para solicitar depoimentos de clientes satisfeitos
output_type: testimonial-request
version: 1.0
category: social_proof
primary_agent: "@clayton-makepeace"
framework: "Prova Social Progressiva"
channels: email, whatsapp, vídeo, escrito
```

## Instruções de Uso

1. Envie o pedido APÓS o cliente obter resultado mensurável
2. Preencha os placeholders {PLACEHOLDER} com dados reais
3. Escolha o formato mais adequado ao perfil do cliente
4. Personalize o tom conforme o relacionamento existente
5. Sempre ofereça um incentivo genuíno pela participação

---

## FRAMEWORK: PROVA SOCIAL PROGRESSIVA

<!-- Clayton Makepeace: "A prova mais poderosa não é o que VOCÊ diz sobre seu produto. É o que seu CLIENTE diz — nas palavras DELE." -->

```
FASE 1: Timing certo (após resultado confirmado)
FASE 2: Pedido inicial (email emocional + facilitação)
FASE 3: Follow-up (menor fricção, opções múltiplas)
FASE 4: Captura do depoimento (escrito ou vídeo)
FASE 5: Incentivo e agradecimento
```

---

## FASE 1: TIMING — Quando Pedir

<!-- Nunca peça depoimento de quem ainda não teve resultado. Espere o "momento wow". -->

```
MOMENTOS IDEAIS para pedir depoimento:

✅ Após o cliente reportar um resultado específico
✅ Após uma mensagem espontânea de agradecimento
✅ Após completar um marco do programa ({MARCO_1}, {MARCO_2})
✅ Após renovação ou recompra (sinal claro de satisfação)
✅ Após indicação espontânea

❌ NUNCA peça:
• Na primeira semana de uso
• Quando o cliente reportou problema recente
• Antes de resolver um ticket de suporte aberto
• Em massa sem personalização
```

## FASE 2: EMAIL 1 — Pedido Inicial

<!-- O segredo é fazer o cliente sentir que a história DELE importa, não que você precisa de marketing. -->

## FASE 4A: ROTEIRO PARA DEPOIMENTO EM VÍDEO

<!-- Vídeo é o formato mais poderoso. Mas a maioria trava porque não sabe o que dizer. Este roteiro resolve isso. -->

### Instruções para o Cliente

```
COMO GRAVAR SEU DEPOIMENTO EM VÍDEO

Duração ideal: 60 a 120 segundos
Formato: Selfie (câmera frontal do celular)
Local: Ambiente silencioso, boa iluminação natural
Roupa: Vista-se como no dia a dia (autenticidade > produção)

NÃO PRECISA:
❌ Câmera profissional
❌ Iluminação especial
❌ Edição ou efeitos
❌ Decorar nada — fale naturalmente

DICA: Grave como se estivesse contando pra um amigo.
```

### Roteiro Guiado (O que dizer)

```
BLOCO 1: QUEM VOCÊ É (10 segundos)
"Oi, meu nome é {SEU_NOME}, sou {PROFISSÃO/CONTEXTO}
de {CIDADE}."

BLOCO 2: COMO VOCÊ ESTAVA ANTES (20-30 segundos)
"Antes de conhecer o {NOME_PRODUTO}, eu estava {SITUAÇÃO_ANTES}.
Meu maior problema era {DOR_PRINCIPAL}.
Eu já tinha tentado {TENTATIVAS_ANTERIORES} e nada funcionava."

BLOCO 3: O QUE MUDOU (20-30 segundos)
"Quando comecei a {USAR/APLICAR} o {NOME_PRODUTO}, a primeira
coisa que percebi foi {PRIMEIRO_RESULTADO}.
Em {TEMPO}, eu consegui {RESULTADO_PRINCIPAL}."

BLOCO 4: RESULTADO CONCRETO (20-30 segundos)
"Hoje, minha realidade é completamente diferente.
{RESULTADO_ESPECÍFICO_COM_NÚMEROS}.
{IMPACTO_NA_VIDA_PESSOAL_OU_PROFISSIONAL}."

BLOCO 5: RECOMENDAÇÃO (10 segundos)
"Se você está na dúvida, meu conselho é: {RECOMENDAÇÃO_GENUÍNA}.
Vale cada centavo."
```

### Perguntas Alternativas (se o cliente preferir ser entrevistado)

```
Use estas perguntas numa call de 10 min (grave com permissão):

1. "Me conta: como era sua situação antes do {NOME_PRODUTO}?"
2. "O que te fez decidir entrar?"
3. "Qual foi o primeiro resultado que você percebeu?"
4. "Qual o resultado mais significativo até agora?"
5. "O que mudou na sua vida/negócio depois disso?"
6. "Se pudesse falar com alguém que está na dúvida, o que diria?"
```

## CHECKLIST DE QUALIDADE

**Timing:**
- [ ] Cliente teve resultado comprovado antes do pedido
- [ ] Não há ticket de suporte aberto
- [ ] Relacionamento está positivo (mensagens recentes OK)

**Pedido:**
- [ ] Email personalizado com resultado específico do cliente
- [ ] Tom emocional e genuíno (não corporativo)
- [ ] Múltiplas opções de formato (escrito, áudio, vídeo)
- [ ] Roteiro/formulário incluso para facilitar
- [ ] Incentivo oferecido (adequado ao perfil)

**Depoimento capturado:**
- [ ] Contém resultado específico com números
- [ ] Inclui transformação antes/depois
- [ ] Linguagem autêntica do cliente (não "polida" demais)
- [ ] Permissão formal obtida (nome, foto, publicação)
- [ ] Cliente aprovou versão formatada antes da publicação

**Formato:**
- [ ] Versão curta (1-2 frases) para ads e headlines
- [ ] Versão média (1 parágrafo) para emails e cards
- [ ] Versão longa (3-5 parágrafos) para sales pages
- [ ] Versão em vídeo (se aplicável)

**Legal:**
- [ ] Consentimento por escrito para uso do depoimento
- [ ] Cliente informado sobre onde será publicado
- [ ] Resultado descrito é factual e verificável
- [ ] Disclaimer de resultado individual quando necessário
