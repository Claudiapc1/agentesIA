## Instruções de Uso

1. Defina o objetivo do carrossel: educar, vender, gerar leads ou engajar
2. Preencha os placeholders [PLACEHOLDER] com dados reais
3. Cada slide deve ter POUCO texto — 30-60 palavras no máximo
4. O hook (slide 1) define se o carrossel será consumido ou ignorado
5. Escreva a legenda DEPOIS dos slides — ela complementa, não repete

---

## PRINCÍPIO CENTRAL

O carrossel é o formato de maior retenção nas redes sociais. Cada slide é uma "micro-página" que precisa fazer o leitor deslizar para o próximo. **Se o slide 1 não prende, ninguém vê o slide 2. Se o penúltimo slide não cria desejo, ninguém chega no CTA.** Pense no carrossel como uma mini-VSL em imagens.

---

## ESTRUTURA GERAL (7 Slides Padrão)

```
SLIDE 1: HOOK (parar o scroll)
SLIDE 2: PROBLEMA / CONTEXTO (identificação)
SLIDE 3: INSIGHT / REVELAÇÃO (valor)
SLIDE 4-6: CONTEÚDO / PASSOS / LISTA (entrega)
SLIDE 7: CTA (ação)
```

---

## SLIDE 1: HOOK

**Objetivo:** Parar o scroll. O leitor decide em 1.5 segundos se vai deslizar.

### Formatos de Hook

**Formato A: Promessa Direta**
```
[NUMERO] [COISAS] Que [AVATARES] de Sucesso
Fazem Todos os Dias

(e que você provavelmente ignora)
```

**Formato B: Pergunta Provocativa**
```
Por Que Você [ACAO COMUM]
e Mesmo Assim Não [RESULTADO]?

A resposta está no slide 4 →
```

**Formato C: Declaracao Contraintuitiva**
```
[CONSELHO COMUM] é o Pior
Conselho Que Você Pode Seguir

Deixa eu explicar →
```

**Formato D: Numero + Resultado**
```
De R$ [X] Para R$ [Y]
em [TEMPO]

O passo a passo completo →
```

**Formato E: "Não Faça Isso"**
```
PARE de [ACAO COMUM]
Se Você Quer [RESULTADO]

(Faça isso em vez disso →)
```

**Formato F: Lista / Framework**
```
O Framework de [AREA]
Que [EXPERT/EMPRESA] Usa:

[NOME DO FRAMEWORK] →
```

### Regras do Slide 1
- Texto grande e legível (mesmo no feed, sem expandir)
- Máximo 15-20 palavras
- Contraste visual forte
- Seta ou indicação de "deslize" (→)

## SLIDE 2: PROBLEMA / CONTEXTO

**Objetivo:** Criar identificação. O leitor pensa "isso sou eu".

```
A maioria dos [AVATARES]:

□ [COMPORTAMENTO COMUM 1]
□ [COMPORTAMENTO COMUM 2]
□ [COMPORTAMENTO COMUM 3]

E se pergunta por que
[RESULTADO] não acontece.

O problema não é esforço.
É estratégia →
```

**Alternativa:**
```
Você já [EXPERIENCIA FRUSTRANTE]?

Já [TENTATIVA QUE FALHOU]?

Já [SENTIMENTO DE FRUSTACAO]?

Então esse carrossel vai
mudar sua perspectiva →
```


### Formato Storytelling
```
SLIDE 3:
[TEMPO] atrás, eu estava
[SITUACAO ANTES].

Eu tentava [ABORDAGEM ERRADA]
e não funcionava.

---

SLIDE 4:
```

### Regras dos Slides de Conteúdo
- 1 ideia por slide — nunca 2
- Máximo 40-60 palavras por slide
- Use ícones/emojis para organizar visualmente
- Hierarquia clara: título > corpo > exemplo

## SLIDE FINAL: CTA

**Objetivo:** Converter atenção em ação. Diga exatamente o que fazer.

### CTA para Engajamento
```

1. Salve para consultar depois
2. Compartilhe com alguém que precisa
3. Comente qual [PONTO] você vai aplicar primeiro

Sigo compartilhando conteúdo assim
toda [FREQUENCIA]. Siga para não perder →
```

### CTA para Gerar Leads
```
Quer o [MATERIAL COMPLEMENTAR]
com [BENEFICIO]?

Comenta "[PALAVRA-CHAVE]"
que eu te envio no DM

(ou clique no link da bio)
```

### CTA para Vender
```

Criei o [NOME DO PRODUTO]
exatamente para isso.

Link na bio →
[ou comenta "EU QUERO"]

```

```
Ajudo [AVATARES] a [RESULTADO]
através de [METODO].

Siga para mais conteúdos assim.
Ative o sininho →
```

## VARIAÇÕES POR PLATAFORMA

### Instagram
- Formato: 1080x1350px (vertical) — melhor para feed
- Slides: 5-10 (ideal: 7)
- Texto: Grande, legível sem expandir
- CTA: "Salve", "Compartilhe", "Comenta [palavra]"

### LinkedIn
- Formato: 1080x1080px (quadrado) ou PDF
- Slides: 5-12 (aceita mais conteúdo)
- Texto: Pode ser mais denso, profissional
- CTA: "Reposte", "Comente sua experiência"
- Tom: Mais analítico, dados e frameworks

### Facebook
- Formato: 1080x1080px
- Slides: 5-8 (atenção menor)
- Texto: Mais curto que LinkedIn
- CTA: "Compartilhe", "Marque alguém"

## CONDIÇÕES DE VETO (quando este template falha)

- **Slide 1 fraco:** Se o hook não para o scroll, o carrossel inteiro morre. Gaste 50% do tempo de criação no slide 1.
- **Texto demais por slide:** Se o leitor precisa "ler um parágrafo" em cada slide, ele abandona. Máximo 60 palavras.
- **Slides idênticos visualmente:** Se todos os slides parecem iguais, não há estímulo visual para continuar deslizando. Varie cores, layouts, ícones.
- **Conteúdo genérico:** "Seja consistente" e "tenha foco" não são insights — são obviedades. Entregue algo que o leitor NÃO sabia.
- **CTA ausente ou fraco:** Se o último slide não diz exatamente o que fazer, você educou de graça.
- **Sem legenda:** A legenda complementa o carrossel com contexto e hashtags. Sem ela, você perde alcance.
