## FÓRMULAS DE HEADLINE PARA CAPTURA

### Fórmula 1: Resultado + Prazo (ALTA CONVERSÃO)
```
[RESULTADO ESPECÍFICO] em [PRAZO] — [SEM OBJEÇÃO COMUM]

Exemplos:
• "Monte seu funil de vendas em 48h — mesmo sem saber programar"
• "Reduza 10h semanais de operação em 30 dias — sem demitir ninguém"
```

### Fórmula 2: Como + Resultado (EDUCACIONAL)
```
Como [PERFIL] [RESULTADO] [DIFERENCIAL]

Exemplos:
• "Como empresários de R$ 100k+/mês estão saindo às 18h todos os dias"
• "Como donos de agência estão fechando 3 contratos/semana no orgânico"
```

### Fórmula 3: O Que + Por Que (CURIOSIDADE)
```
[NÚMERO] [ELEMENTOS] que [RESULTADO] (e [REVELAÇÃO])

Exemplos:
• "Os 3 pilares que separam empresários livres de empresários escravos"
• "O painel de 5 indicadores que CEOs de 8 dígitos olham todo dia"
```

### Fórmula 4: Evento + Transformação (PARA EVENTOS)
```
[TIPO EVENTO]: [TRANSFORMAÇÃO] | [DATA/LOCAL]

Exemplos:
• "IMERSÃO: De operador a gestor em 2 dias | 21-22 Fev, São José dos Campos"
• "WORKSHOP AO VIVO: Monte sua máquina de vendas | Quinta, 20h"
```

## CHECKLIST DE VALIDAÇÃO — PÁGINA DE CAPTURA

### Obrigatório (Oráculo Adaptado):

| # | Critério | ✅/❌ |
|---|----------|-------|
| 1 | Headline tem RESULTADO ESPECÍFICO (não genérico)? | |
| 2 | Promessa é EXECUTÁVEL (pessoa sabe o que vai acontecer)? | |
| 3 | Tem FILTRO de público (repele quem não é ideal)? | |
| 4 | CTA é VERBO DE AÇÃO + BENEFÍCIO? | |
| 5 | ZERO palavras proibidas (descubra, aprenda, domine...)? | |

### Sugarman Essenciais para Captura:

| # | Trigger | Presente? |
|---|---------|-----------|
| 1 | Specificity — números e detalhes concretos | |
| 2 | Curiosity — algo que faz querer saber mais | |
| 3 | Sense of Urgency — motivo para agir agora | |
| 4 | Credibility — por que confiar | |
| 5 | Simplicity — fácil de entender em 5 segundos | |

### Teste dos 5 Segundos:
> "Se alguém olhar essa página por 5 segundos, vai entender O QUE é, PRA QUEM é e O QUE FAZER?"

## VARIAÇÕES POR NÍVEL DE CONSCIÊNCIA (Schwartz)

### Nível 1 (Inconsciente do Problema):
- Headline foca na DOR ou sintoma
- "Você trabalha 12h/dia e não sabe por quê?"

### Nível 2 (Consciente do Problema):
- Headline foca no PROBLEMA
- "O gargalo que faz sua empresa depender de você"

### Nível 3 (Consciente da Solução):
- Headline foca na SOLUÇÃO
- "Sistema para sair da operação em 60 dias"

### Nível 4 (Consciente do Produto):
- Headline foca no DIFERENCIAL
- "Por que o Protocolo 360 funciona quando outros métodos falharam"

### Nível 5 (Mais Consciente):
- Headline vai direto ao ponto
- "Imersão Gestão Eficaz — 21 e 22 de Fevereiro — Últimas vagas"
