# Template: Ad Copy (Facebook/Instagram Ads)

```yaml
name: ad-copy-template
description: Templates de anúncios para Facebook e Instagram Ads
output_type: ad-copy
version: 1.0
platforms: [facebook, instagram]
formats: [feed, stories, reels]
```

## Instruções de Uso

1. Escolha o formato adequado ao seu objetivo
2. Preencha os placeholders [PLACEHOLDER]
3. Adapte o tom para sua audiência
4. Teste múltiplas variações (headline, copy, CTA)
5. Respeite os limites de caracteres da plataforma

---

## LIMITES DE CARACTERES

```
FACEBOOK/INSTAGRAM FEED:
- Primary Text: 125 caracteres (visível sem "ver mais")
- Primary Text Total: até 2.200 caracteres
- Headline: 40 caracteres (recomendado)
- Description: 30 caracteres (recomendado)

STORIES/REELS:
- Texto overlay: 10-20 palavras máximo
- Recomendado: deixar o vídeo falar
```

## VARIAÇÕES PARA TESTE A/B

### Estrutura de Teste
```
Teste 1: HEADLINE
- Versão A: Curiosidade
- Versão B: Benefício direto
- Versão C: Pergunta

Teste 2: HOOK (primeira linha)
- Versão A: Estatística
- Versão B: Pergunta
- Versão C: Afirmação bold

Teste 3: CTA
- Versão A: Direto ("Compre agora")
- Versão B: Benefício ("Comece a emagrecer")
- Versão C: Urgência ("Garanta antes que acabe")

Teste 4: FORMATO
- Versão A: Copy curta
- Versão B: Copy média
- Versão C: Copy longa
```

## CHECKLIST FINAL

**Antes de subir o anúncio:**
- [ ] Hook para o scroll nos primeiros 3 segundos
- [ ] Benefício claro e específico
- [ ] CTA direto e visível
- [ ] Sem promessas exageradas (política do Facebook)
- [ ] Imagem/vídeo alinhado com copy
- [ ] Link correto configurado
- [ ] Pixel de conversão instalado
- [ ] Público-alvo definido
- [ ] Orçamento e lance configurados

**Variações para teste:**
- [ ] 2-3 headlines diferentes
- [ ] 2-3 copies diferentes
- [ ] 2-3 criativos diferentes
- [ ] Públicos segmentados
