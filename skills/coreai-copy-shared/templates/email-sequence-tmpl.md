# Template: Sequência de Emails de Vendas

```yaml
name: email-sequence-template
description: Template de sequência de 5 emails para lançamento/evergreen
output_type: email-sequence
version: 1.0
emails: 5
cadence: diária ou a cada 2 dias
```

## Instruções de Uso

1. Preencha os placeholders [PLACEHOLDER] com dados do seu produto
2. Mantenha open loops entre emails para aumentar abertura
3. Personalize o tom de voz para seu avatar
4. Teste subject lines alternativas
5. Configure automação com delays apropriados

---

## VISÃO GERAL DA SEQUÊNCIA

```
EMAIL 1: Hook + Story Setup (Curiosidade + Conexão)
    ↓ [Open Loop: O que descobri...]
EMAIL 2: Backstory + Credibilidade (Autoridade + Identificação)
    ↓ [Open Loop: A virada...]
EMAIL 3: Epifania (Revelação + Mecanismo)
    ↓ [Open Loop: Como aplicar...]
EMAIL 4: Hidden Benefits (Benefícios ocultos + Prova)
    ↓ [Open Loop: Oferta especial...]
EMAIL 5: Urgência + CTA (Fechamento + Escassez)
```

## OPEN LOOPS - TÉCNICAS

### O que são Open Loops
Ganchos narrativos que criam curiosidade e antecipação para o próximo email.

### Técnicas de Open Loop

**1. Promessa Direta**
```
"Amanhã vou te revelar exatamente como..."
```

**2. Teaser Misterioso**
```
"O que vou compartilhar amanhã é algo que 99% das pessoas nunca descobrem..."
```

**3. Pergunta Sem Resposta**
```
"Mas como isso é possível? Amanhã eu explico."
```

**4. Benefício Incompleto**
```
"E isso é só o começo. Amanhã você vai ver o que mais..."
```

**5. História Interrompida**
```
"Foi então que aconteceu algo que mudou tudo. Te conto amanhã."
```

**6. Exclusividade**
```
"Amanhã vou compartilhar algo que nunca revelei publicamente..."
```

## MÉTRICAS DE REFERÊNCIA

### Taxas Saudáveis
```
Taxa de Abertura: 20-40%
Taxa de Clique: 2-5%
Taxa de Resposta: 0.5-2%
Taxa de Desinscrição: <0.5% por email
```

### Otimização
```
Abertura baixa → Testar subject lines
Clique baixo → Revisar CTA e copy
Alta desinscrição → Revisar frequência/relevância
```
