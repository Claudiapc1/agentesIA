```yaml
name: referral-program-template
description: Template para programas de indicação de clientes e recrutamento de afiliados
output_type: referral-program
version: 1.0
category: growth
primary_agent: "@frank-kern"
framework: "Dual Growth Engine"
channels: email, página web, WhatsApp
```

## Instruções de Uso

1. Escolha a parte relevante: indicação de clientes OU recrutamento de afiliados (ou ambos)
2. Preencha os placeholders {PLACEHOLDER} com dados reais
3. Defina incentivos ANTES de lançar (o que cada parte ganha)
4. Teste com 10-20 clientes/afiliados antes de escalar
5. Monitore métricas semanalmente nos primeiros 30 dias

---

## FRAMEWORK: DUAL GROWTH ENGINE

<!-- Frank Kern: "O melhor marketing que existe é um cliente satisfeito falando de você. Seu trabalho é facilitar essa conversa." -->

```
PARTE 1: INDICAÇÃO DE CLIENTES
→ Clientes satisfeitos indicam amigos/colegas
→ Ambos ganham (quem indica + quem é indicado)

PARTE 2: RECRUTAMENTO DE AFILIADOS
→ Profissionais promovem seu produto por comissão
→ Parceria de longo prazo com suporte e materiais
```

## MÉTRICAS DO PROGRAMA

```
KPIs PROGRAMA DE INDICAÇÃO:

• Taxa de indicação (clientes que indicam): meta > {PERCENTUAL}%
• Taxa de conversão de indicados: meta > {PERCENTUAL}%
```
