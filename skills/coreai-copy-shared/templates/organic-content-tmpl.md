## REGRA 50-30-20 DE CONTEÚDO

<!-- Esta regra define a distribuição ideal de tipos de conteúdo no calendário -->

## FORMATO 1: POST ÚNICO (Feed)

### Para: Instagram, LinkedIn, Facebook

**Template A: Post de Valor (50%)**
```
{HOOK — primeira linha que para o scroll}

{ESPAÇO}

{CORPO — 3 a 5 parágrafos curtos com insight prático}

<!-- O corpo deve entregar valor real. Não enrole. Ensine algo aplicável. -->

Parágrafo 1: {CONTEXTO — por que isso importa}
Parágrafo 2: {INSIGHT — o que a maioria não sabe}
Parágrafo 3: {APLICAÇÃO — como usar isso hoje}
Parágrafo 4: {RESULTADO — o que muda quando aplica}

{ESPAÇO}

{CTA DE ENGAJAMENTO — pergunta ou pedido de interação}

<!-- Evite CTAs de venda em posts de valor. O objetivo é engajamento. -->
```

**Exemplo:**
```
A maioria dos copywriters escreve para impressionar.
Os que faturam escrevem para conectar.

Existe uma diferença enorme entre "escrever bonito"
e "escrever que vende".

Copy que vende faz 3 coisas:
1. Identifica a dor real (não a superficial)
2. Agita com consequências futuras
3. Apresenta a solução como inevitável

Quando parei de tentar ser criativo e comecei
a ser específico, meus resultados mudaram.

Qual dessas 3 você mais precisa melhorar?
Comenta aqui 👇
```

**Template B: Post de Autoridade (30%)**
```
{RESULTADO CONCRETO — número, conquista, marco}

{ESPAÇO}

{BASTIDOR — como chegou nesse resultado}

<!-- Mostre o processo, não só o resultado. Pessoas se conectam com a jornada. -->

{LIÇÃO PRINCIPAL — o que aprendeu}

{ESPAÇO}

{CTA — convite para seguir/acompanhar a jornada}
```

**Exemplo:**
```
R$ 47.000 em uma semana com um único e-mail.

Não foi sorte. Foi método.

Passei 3 dias pesquisando a dor do meu avatar.
Escrevi 7 versões do assunto.
Testei 3 hooks diferentes.

O e-mail vencedor tinha 287 palavras.
Zero imagens. Zero firula.

Só clareza sobre o problema e uma oferta irresistível.

A lição? Pesquisa > talento.

Quer ver os bastidores dos meus próximos lançamentos?
Ativa o sininho 🔔
```

## HOOKS POR TIPO DE CONTEÚDO

### Hooks de Valor
```
• "A maioria das pessoas não sabe que {FATO SURPREENDENTE}"
• "{NÚMERO} erros que estão sabotando seu {RESULTADO}"
• "Se você {SITUAÇÃO}, para tudo e lê isso"
• "Ninguém te conta isso sobre {TÓPICO}"
• "O framework que uso pra {RESULTADO} toda semana"
```

### Hooks de Autoridade
```
• "Em {TEMPO}, eu {RESULTADO IMPRESSIONANTE}"
• "Isso me custou R$ {VALOR} pra aprender"
• "O que {TEMPO} de {EXPERIÊNCIA} me ensinou"
• "Bastidores de como fiz {RESULTADO}"
• "O conselho que mudou minha {ÁREA}"
```

### Hooks de Venda
```
• "Você está a {NÚMERO} passos de {RESULTADO}"
• "Se eu pudesse voltar no tempo, teria {AÇÃO} antes"
• "Cansado de {PROBLEMA}? Eu resolvi isso com {MÉTODO}"
• "Abri {NÚMERO} vagas para {OFERTA}"
• "{RESULTADO DO CLIENTE} — e você pode ser o próximo"
```

```
- Tom: profissional mas humano, storytelling corporativo
- Hashtags: 3-5 relevantes
- Formato preferido: post texto > carrossel > vídeo
- Horários: 7-9h, 12-13h (dias úteis)

```

## FRAMEWORK DAN KOE: CONTEÚDO QUE CONSTRÓI NEGÓCIO

<!-- Referência: Dan Koe — criador de conteúdo que gera autoridade e venda simultaneamente -->

### Pilares do conteúdo estratégico

```
1. IDENTIDADE: Quem você é e o que representa
   → Posts sobre sua filosofia, valores, visão de mundo

2. PROBLEMA: O que seu avatar enfrenta
   → Posts que nomeiam dores que o avatar nem sabe que tem

3. SOLUÇÃO: Seu método/framework único
   → Posts que ensinam pedaços do seu método

4. PROVA: Resultados seus e de clientes
   → Posts com números, cases, transformações

5. OFERTA: O que você vende
   → Posts que apresentam seu produto como consequência natural
```

### Proporção semanal sugerida (7 posts/semana)

```
- 2x Identidade/Filosofia (autoridade)
- 2x Problema + Solução (valor)
- 2x Prova social / bastidores (autoridade)
- 1x Oferta direta (venda)
```

## CHECKLIST DE QUALIDADE

**Antes de publicar:**
- [ ] Hook interrompe o scroll (testou ler só a primeira linha?)
- [ ] Conteúdo entrega valor real (a pessoa sai melhor do que entrou?)
- [ ] Texto está adaptado para a plataforma escolhida
- [ ] CTA é claro e coerente com o objetivo do post
- [ ] Regra 50-30-20 está sendo respeitada no calendário
- [ ] Tom está alinhado com a voz da marca/criador
- [ ] Formatação facilita a leitura (espaçamentos, quebras de linha)
- [ ] Hashtags são relevantes e no número certo para a plataforma
- [ ] Horário de publicação é adequado para a plataforma
- [ ] Visual/criativo está coerente com o texto (se aplicável)

**Variações para teste:**
- [ ] 2-3 hooks diferentes para o mesmo conteúdo
- [ ] Formatos diferentes (post vs carrossel vs reel)
- [ ] CTAs diferentes (engajamento vs lead vs venda)
