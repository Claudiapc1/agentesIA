## Visão Geral

O **FLI (Funil de Lucro Imediato)** é um funil de conversão direto para mentorias high-ticket que transforma sua audiência quente em clientes qualificados através de **seleção ativa** e **posicionamento de autoridade**.

### Conceito Central

> **Em vez de "aceitar" qualquer pessoa, você SELECIONA quem pode trabalhar com você. Isso inverte a dinâmica de poder e atrai apenas prospects prontos para pagar alto valor.**

### Quando Usar

- **Primeira venda**: Pode ser o PRIMEIRO funil para fazer suas primeiras vendas
- **Uso recorrente**: Ativar audiência de tempos em tempos
- **Frequência**: Sempre que tiver novas vagas ou quiser reativar leads quentes
- **Mínimo**: 500 seguidores engajados

---

## Fluxo Completo do Funil

| Etapa | Ação | Resultado |
|-------|------|-----------|
| 1. DIVULGAÇÃO | Feed + Stories + WhatsApp | Alcance máximo da audiência quente |
| 2. LEVANTADA DE MÃO | Prospects respondem/comentam | Lista de leads qualificados |
| 3. CONVERSA (SCRIPT) | Script de 5 passos no Direct | Prospect aquecido e pronto |
| 4. APLICAÇÃO | Lead preenche formulário | Dados para análise |
| 5. FECHAMENTO | Call de vendas | Cliente pagando |

## Passo 2: Script de Conversa (Após Levantada de Mão)

Quando alguém levanta a mão, use este script no Direct/WhatsApp para levar até o formulário.

### Passo 1: Confirmação

```
Opa, [Nome]! Vi que você se identificou.
Me conta: o que mais te chamou atenção no que eu falei?
```

**Objetivo:** Confirmar interesse real e aquecer a conversa

### Passo 2: Dor Atual

```
Entendi. E hoje, qual é o maior desafio que você enfrenta
em relação a [resultado que ele quer]?
```

**Objetivo:** Identificar a dor principal e nível de consciência

### Passo 3: Tentativas Anteriores

```
Já tentou resolver isso antes? O que já fez até agora?
```

**Objetivo:** Ver histórico e por que não funcionou

### Passo 4: Urgência

```
E se nada mudar nos próximos 90 dias,
como isso impacta você/seu negócio?
```

**Objetivo:** Criar senso de urgência

### Passo 5: Transição para Aplicação

```
Perfeito. Olha, pelo que você me contou, faz total sentido
a gente conversar mais a fundo.

Vou te passar um formulário rápido — ele me ajuda a entender
seu cenário completo.

Depois disso, a gente agenda uma conversa. Pode ser?
```

**Objetivo:** Levar para aplicação SEM resistência

**REGRAS:**
- Cada passo é uma mensagem separada
- Espere a resposta antes de passar para o próximo
- NUNCA fale de preço nessa fase
- Objetivo é APENAS levar para o formulário

---

### 🛑 VETO CONDITIONS — Conversa → Formulário

## Passo 4: Roteiro de Fechamento

### Roteiro 1: Versão Direta

**Quando usar:** Lead qualificado, com dinheiro, urgência clara.

**#1 Contexto**
```
Que bom falar contigo, [Nome].
Antes da gente ir pro ponto central, só pra entender:
como você me conheceu?
```

**#2 Validação do Formulário**
```
Revisando sua aplicação aqui, você comentou que:
- [Resgatar faturamento]
- [Resgatar problema principal]
- [Resgatar desejo/resultado]

Só pra validar: tudo isso continua atual?
```

**#3 Por Que Agora?**
```
Por que você acha que essa oportunidade faz sentido pra você agora?
```

**#4 Por Que Você?**
```
Com poucas vagas disponíveis, eu preciso ser cirúrgico.
Por que eu deveria escolher você?
```

**#5 Decisão de Investimento**
```
Vamos falar de decisão:

Essa oportunidade exige investimento: R$30 mil à vista
ou 3x de R$12 mil.

Você tem possibilidade de investir agora?
```

**Se NÃO:** Agradeça e encerre.
**Se SIM:** Continue...

**#6 Como Vai Arrumar o Dinheiro?**
```
Como você vai organizar esse valor?
Quero clareza. Não aceito "vou ver ainda".
```

**#7 Fechamento com Urgência**
```
Fechando:

Vou deixar sua vaga em aberto por 24 horas.

Se o pagamento não for feito, eu passo para o próximo nome da fila.

Posso contar com você até amanhã?
```

## Cronograma de Execução

### Preparação (48h antes)
- [ ] Parar de postar Stories
- [ ] Preparar imagem do feed
- [ ] Escolher legenda (1, 2 ou 3)
- [ ] Preparar mensagens WhatsApp
- [ ] Configurar formulário de aplicação

### Dia da Divulgação
**Manhã (8h-10h):**
- [ ] Postar Feed com legenda completa
- [ ] Postar Story Único (apenas 1)
- [ ] Enviar Mensagem 1 no WhatsApp

**Durante o dia:**
- [ ] Monitorar comentários no feed
- [ ] Responder stories rapidamente
- [ ] Acompanhar respostas no WhatsApp
- [ ] VELOCIDADE é crítica nas primeiras 2-3 horas

### 24h Após Divulgação
- [ ] NÃO postar outros stories
- [ ] Continue respondendo
- [ ] Analise formulários
- [ ] Agende calls de fechamento

### 48h-72h Após
- [ ] Análise completa dos resultados
- [ ] Follow-up com leads que não agendaram
- [ ] Execução das calls
- [ ] Planejamento da próxima rodada
