# Swipe File de Bullets

## Introdução

> "Um bom bullet pode vender um produto inteiro. Bullets são a munição da sua carta de vendas." — Gary Halbert

Bullets (também chamados de fascinations) são pequenos parágrafos ou frases que destacam benefícios, revelam segredos ou criam curiosidade intensa. São a espinha dorsal de cartas de vendas, VSLs e páginas de captura.

---

## 1. Bullets de "Segredo Revelado"

### Clássicos

1. **"O segredo de uma página que transforma prospects frios em compradores famintos... página 47"**
   - *Análise:* Promessa específica + número de página cria tangibilidade
   - *Fórmula:* O segredo de [fonte] que/para [resultado]... página [X]

2. **"O ingrediente 'proibido' que faz [resultado] em metade do tempo (e por que [autoridades] não querem que você saiba)"**
   - *Análise:* Proibido + conspiração + resultado rápido
   - *Fórmula:* O [elemento] proibido que [resultado] (e por que [autoridade] esconde)

3. **"A técnica de 'bastidores' usada por [experts] para [resultado] - revelada pela primeira vez"**
   - *Análise:* Exclusividade + autoridade + primeira vez
   - *Fórmula:* A técnica de bastidores de [grupo] para [resultado] - revelada

4. **"Por que os melhores [profissionais] NUNCA [ação comum] - e o que fazem no lugar"**
   - *Análise:* Contra-intuitivo + curiosidade sobre alternativa
   - *Fórmula:* Por que [experts] nunca [ação esperada] - e o que fazem

5. **"O 'atalho' de [grupo de elite] para [resultado] que levaria [tempo maior] do jeito tradicional"**
   - *Análise:* Atalho + comparação temporal + exclusividade
   - *Fórmula:* O atalho de [grupo] para [resultado] vs [método tradicional]

### Variações Modernas

6. **"O hack de R$0 que gera mais resultado que [solução cara de R$X]"**

7. **"A 'brecha' legal que [grandes players] usam para [vantagem] (página 34)"**

8. **"O ingrediente secreto de [marca famosa] que você pode replicar em casa por centavos"**

9. **"O truque de 3 segundos que [profissionais] usam antes de [ação] para [resultado]"**

## 12. Fórmulas Extraídas

### Fórmula 1: Segredo + Fonte + Resultado
```
O segredo de [fonte inesperada/admirada] para [resultado desejado]

Exemplos:
- O segredo de monges tibetanos para foco inabalável
- O segredo de vendedores de R$1M/ano para fechar em uma ligação
- O segredo de atletas olímpicos para recuperação acelerada
```

### Fórmula 2: Número + Tipo + Resultado + Diferencial
```
[X] [tipo de recurso] para [resultado] que [diferencial]

Exemplos:
- 7 scripts de vendas que funcionam mesmo com prospects frios
- 12 receitas fitness que crianças adoram
- 23 templates de email que geram respostas em 24 horas
```

### Fórmula 3: Erro + Custo + Frequência
```
O erro de R$[valor] que [X]% das pessoas cometem [frequência]

Exemplos:
- O erro de R$5.000 que 90% dos investidores cometem todo ano
- O erro de R$500/mês que quase toda empresa comete sem perceber
- O erro fiscal de R$3.000 que autônomos cometem na declaração
```

### Fórmula 4: Ação + Tempo + Resultado
```
Como [ação] em [tempo específico] para [resultado]

Exemplos:
- Como escrever uma headline em 3 minutos que vende
- Como preparar uma semana de refeições em 2 horas
- Como criar um funil de vendas em 1 tarde
```

### Fórmula 5: Contra-intuitivo + Prova
```
Por que [ação inesperada] é [melhor/pior] para [objetivo] (estudos provam)

Exemplos:
- Por que dormir menos pode aumentar sua produtividade (estudo de Stanford)
- Por que cobrar mais atrai melhores clientes (dados de 500 freelancers)
- Por que NÃO postar todo dia aumenta engajamento (análise de 10k perfis)
```

### Fórmula 6: Pergunta + Consequência Oculta
```
Você está [ação comum]? [Consequência que não sabia]

Exemplos:
- Você está economizando na poupança? Está perdendo R$12k/ano
- Você está usando hashtags? Pode estar limitando seu alcance
- Você está fazendo cardio em jejum? Pode estar queimando músculo
```

### Fórmula 7: Página/Localização + Tesouro
```
[Localização]: [Recurso valioso] que [promessa irresistível]

Exemplos:
- Página 67: O template que fechou R$500k em contratos
- Módulo 4: A automação que economiza 15 horas/semana
- Bônus 3: Os 50 emails que você pode copiar e colar
```

### Fórmula 8: Antes/Depois + Timeline
```
De [estado ruim] para [estado bom] em [tempo] - [prova/caso]

Exemplos:
- De 0 a 10k seguidores em 60 dias - caso da Maria
- De dívida de R$50k para patrimônio de R$200k em 3 anos
- De iniciante a primeira venda em 14 dias - método validado
```

## 13. Checklist de Bullet Eficaz

Antes de finalizar seu bullet, verifique:

- [ ] **Cria curiosidade irresistível?** O leitor PRECISA saber mais?
- [ ] **É específico?** Números, páginas, valores, tempos?
- [ ] **Tem benefício claro?** O que o leitor ganha?
- [ ] **É credível?** Não parece bom demais para ser verdade?
- [ ] **É único?** Diferente dos outros bullets da lista?
- [ ] **Tem gancho emocional?** Medo, desejo, curiosidade?
- [ ] **É escanável?** Funciona mesmo em leitura rápida?
- [ ] **Fecha um loop?** Deixa algo em aberto que só o produto resolve?

## 14. Regras de Ouro para Bullets

1. **Um bullet = uma ideia** - Não sobrecarregue.

2. **Comece forte** - As primeiras palavras determinam se leem o resto.

3. **Seja específico** - "Página 47" vende mais que "neste livro".

4. **Misture tipos** - Alterne entre segredos, erros, como-fazer, números.

5. **Os melhores bullets no início e fim** - Efeito primazia e recência.

6. **Bullets vendem o produto** - Cada um deve criar desejo de compra.

7. **Teste incansavelmente** - Pequenas mudanças geram grandes diferenças.

> "Se você não consegue escrever bullets que fazem as pessoas perderem o sono de curiosidade, volte e estude seu mercado." — John Carlton
