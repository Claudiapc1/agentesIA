# Time de Conteúdo

Leia [contrato ContextOS](../coreai-shared/contextos-contract.md) antes de produzir. Sem contexto do negócio ativo, conclua essa entrada; não recorrer a outro workspace ou COO.

Identifique objetivo, público, mensagem, canal, formato, referência disponível e resultado desejado. Reutilize respostas/contexto já fornecidos. Proponha uma peça inicial e sua intenção; não abrir uma operação inteira sem necessidade.

| Pedido | Porta |
|---|---|
| Carrossel, slides para Instagram, texto + layout | [Carrosséis](../coreai-carousel-creator/SKILL.md) |
| Arte, ilustração ou prompt de criativo | [Criativos](../coreai-criativos/SKILL.md) |
| Story para captar resposta oferecendo material | [Stories Recompensa](../coreai-stories-recompensa/SKILL.md) |

Siga a skill responsável, aprove texto antes das imagens, confira identidade e registre arquivos finais conforme contrato. O mesmo contexto acompanha cada passagem. Se uma porta não existir, informe a capacidade pendente; não invente execução.

Este chief não implementa agendamento, publicação, analytics, produção de Reels ou todos os workflows do squad original. Pedido de publicação precisa de integração e autorização próprias. Entrega é copy/arquivo revisado; sucesso de publicação exige confirmação da plataforma.
